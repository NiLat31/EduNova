Integration of
1/(x² + a²).

Learn to recognize the standard form, find the value of a, and apply the inverse tangent result with confidence.

TOPIC 04 / 08

The standard form

Some integrals can be evaluated by recognizing a standard form. One of the most important forms in this part of integration involves a quadratic expression of the form x² + a².

The formula

When the denominator is in the form x² + a², we can use the following standard result:

STANDARD RESULT
∫ 1/(x² + a²) dx = 1/a tan⁻¹(x/a) + C
The key idea

Before using the formula, make sure the denominator is actually in the form x² + a². The value of a must be identified correctly first.

How to find a

This is one of the most important parts of this topic. The number added to x² is a², not a. To find a, take the positive square root of that number.

Compare the denominator

Always compare the expression you have with the standard form:

x² + a²
↔
x² + 25
STEP 01

Identify the number added to x².

STEP 02

Set a² equal to that number.

STEP 03

Take the positive square root to find a.

Worked examples

EXAMPLE 01
Finding a directly

Evaluate:

∫ 1/(x² + 25) dx

Compare the denominator with x² + a²:

a² = 25

Take the positive square root:

a = 5

Now substitute a = 5 into the standard formula.

ANSWER
∫ 1/(x² + 25) dx = 1/5 tan⁻¹(x/5) + C
EXAMPLE 02
When a coefficient must be factored out

Evaluate:

∫ 1/(4x² + 36) dx

The denominator is not yet in the required form. Factor out 4:

4x² + 36 = 4(x² + 9)

Therefore:

∫ 1/[4(x² + 9)] dx = 1/4 ∫ 1/(x² + 9) dx

Now compare x² + 9 with x² + a²:

a² = 9   ⇒   a = 3

Apply the formula:

ANSWER
1/12 tan⁻¹(x/3) + C
EXAMPLE 03
Another value of a

Evaluate:

∫ 1/(x² + 49) dx

Compare with x² + a²:

a² = 49   ⇒   a = 7
ANSWER
1/7 tan⁻¹(x/7) + C

How to recognize the form

The formula should not be used just because an integral contains x². The denominator must be capable of being written in the form x² + a².

Directly recognizable

x² + 16 is already in the required form. Here, a² = 16, so a = 4.

Rearrangement needed

9x² + 36 needs a common factor removed first: 9(x² + 4). Now a² = 4, so a = 2.

Common mistakes

MISTAKE 01

Confusing a² with a

If a² = 25, then a = 5, not 25.

MISTAKE 02

Not factoring first

If there is a common coefficient, factor it out before applying the standard result.

MISTAKE 03

Forgetting 1/a

The answer is not simply tan⁻¹(x/a). The factor 1/a must be included.

MISTAKE 04

Forgetting + C

Remember to include the constant of integration in an indefinite integral.

The method in one view

01

Look at the denominator and try to write it as x² + a².

02

If necessary, factor out a common coefficient.

03

Identify a² and take the positive square root to find a.

04

Apply the formula and simplify your answer.

05

Include the constant of integration, C.
