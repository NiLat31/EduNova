Integration of
1/(x² + a²).

Learn to recognize the standard form, find the value of a, and apply the inverse tangent result with confidence.

04 / 08

The standard form.

Some integrals can be recognized immediately because they match a standard result. One of the most important forms is the integral of 1 divided by x² + a².

The formula

When an integral has the form shown below, we can use the standard inverse tangent result directly.

∫ 1 x² + a² dx = 1 a tan⁻¹ ( x a ) + C
KEY IDEA

The most important step is recognizing the value of a² in the denominator. Once a is identified, the formula can be applied directly.

How to find a

Compare the denominator of the integral with the standard expression x² + a². The number added to x² is a², not a.

x² + a²
↔
x² + 25
STEP 01

Identify a²

Look at the constant added to x².

STEP 02

Find a

Take the positive square root of a².

STEP 03

Use the formula

Substitute a into the standard result.

Worked examples

EXAMPLE 01

∫ 1 x² + 25 dx

Here, a² = 25, so a = 5. Substitute a = 5 into the standard formula.

∫ 1 x² + 25 dx = 1 5 tan⁻¹ ( x 5 ) + C
EXAMPLE 02

∫ 1 4x² + 36 dx

First factor 4 from the denominator:

4x² + 36 = 4(x² + 9)

Therefore, a² = 9 and a = 3.

1 12 tan⁻¹ ( x 3 ) + C
EXAMPLE 03

∫ 1 x² + 49 dx

Since a² = 49, we have a = 7.

1 7 tan⁻¹ ( x 7 ) + C

How to recognize the form

Before integrating, check whether the denominator can be written as x² + a². This quick recognition step can save a lot of unnecessary work.

✓

x² + 4

This matches the standard form because 4 = 2².

✓

x² + 16

This matches because 16 = 4².

✓

x² + 81

This matches because 81 = 9².

Common mistakes

01

Confusing a² with a. If a² = 25, then a = 5, not 25.

02

Forgetting to factor out a constant from the denominator when necessary.

03

Using x/a incorrectly inside the inverse tangent.

04

Forgetting the constant of integration, C.

Quick summary

  1. Recognize the denominator as x² + a².
  2. Identify a².
  3. Find a by taking the square root.
  4. Apply ∫ 1 x² + a² dx = 1 a tan⁻¹ ( x a ) + C
  5. Always include the constant C.
