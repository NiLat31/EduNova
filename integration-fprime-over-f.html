Integration • Topic 05

Integrating
f′(x) / f(x)

Learn how to recognize when the numerator is the derivative of the denominator, and use this pattern to integrate functions involving natural logarithms.

f′/f
01 • The idea

Recognizing the pattern

Some integrals become much easier when the numerator is related to the derivative of the denominator. The important pattern is a function divided by its own derivative:

∫ f′(x) f(x) dx = ln|f(x)| + C

The main skill is not simply memorizing the formula. You need to look at the denominator, differentiate it, and then compare the result with the numerator.

The key question

Whenever you see a fraction inside an integral, ask: “Is the numerator the derivative of the denominator?”

02 • The rule

The key integration rule

If the numerator is exactly the derivative of the denominator, the integral is the natural logarithm of the denominator.

∫ f′(x) f(x) dx = ln|f(x)| + C

The absolute value is important because the natural logarithm is defined for positive inputs. Writing ln|f(x)| gives the general result.

03 • Recognition

How to recognize the form

There are three simple steps to follow.

1 Look at the denominator

Treat the denominator as the function f(x).

2 Differentiate the denominator

Find f′(x).

3 Compare it with the numerator

If the numerator is exactly f′(x), use the rule directly. If it is a constant multiple of f′(x), take that constant into account.

Exact match

Numerator = derivative of denominator. Use the rule directly.

Constant missing

Numerator is a constant multiple of the derivative. Rewrite it using that constant.

No match

The numerator is not related to the derivative. This rule cannot be used directly.

04 • Worked Example 1

When the derivative matches exactly

∫ 2x x² + 5 dx

First, look at the denominator:

f(x) = x² + 5

Differentiate it:

f′(x) = 2x

The numerator is 2x, so it matches f′(x) exactly.

∫ 2x x² + 5 dx = ln|x² + 5| + C

Since x² + 5 is always positive for real x, the absolute value may be omitted here:

ln(x² + 5) + C
05 • Worked Example 2

When a constant is missing

This is one of the most important cases to understand. Sometimes the numerator is not exactly the derivative of the denominator, but it becomes the derivative after multiplying by a constant.

∫ x x² + 4 dx

The denominator is:

f(x) = x² + 4

Its derivative is:

f′(x) = 2x

But our numerator is only x. The derivative is 2x, so the factor 2 is missing.

We can rewrite x using the derivative:

x = 1 2 (2x)

Therefore:

∫ x x² + 4 dx = 1 2 ∫ 2x x² + 4 dx

Now the numerator matches the derivative of the denominator. Applying the rule:

= 1 2 ln|x² + 4| + C

Remember the constant

If the numerator is missing a constant factor, you must compensate for it using its reciprocal.

Missing factor 2 → multiply the integral by 1/2.

Missing factor 5 → multiply the integral by 1/5.

Missing factor 3 → multiply the integral by 1/3.

06 • Worked Example 3

A larger constant

∫ 3x² x³ + 7 dx

Let:

f(x) = x³ + 7

Differentiate:

f′(x) = 3x²

This time the numerator matches exactly.

∫ 3x² x³ + 7 dx = ln|x³ + 7| + C
07 • Worked Example 4

When the derivative is hidden inside the numerator

∫ 6x² - 4 2x³ - 4x + 9 dx

Take the denominator:

f(x) = 2x³ - 4x + 9

Differentiate it:

f′(x) = 6x² - 4

The numerator is exactly the derivative of the denominator.

= ln|2x³ - 4x + 9| + C
08 • Worked Example 5

When the numerator is a multiple of the derivative

∫ 4x + 6 2x² + 6x + 5 dx

Differentiate the denominator:

f′(x) = 4x + 6

The numerator matches exactly, so:

= ln|2x² + 6x + 5| + C

Notice that we do not need to expand, simplify, or change the denominator. Once the derivative is recognized, the integral follows directly.

09 • Worked Example 6

A trickier missing constant

∫ 2x² - 1 2x³ - 3x + 8 dx

Differentiate the denominator:

f′(x) = 6x² - 3

The numerator is not the derivative exactly. However:

2x² - 1 = 1 3 (6x² - 3)

Therefore, the numerator is one third of the derivative.

∫ 2x² - 1 2x³ - 3x + 8 dx = 1 3 ∫ 6x² - 3 2x³ - 3x + 8 dx
= 1 3 ln|2x³ - 3x + 8| + C

The pattern to remember

If the numerator is k f′(x), then:

∫ k f′(x) f(x) dx = k ln|f(x)| + C

If the numerator is only 1/k of the derivative, the answer contains the factor 1/k.

10 • Important distinction

Not every fraction has this form

You should never assume that every fraction inside an integral can be solved using this rule. Always differentiate the denominator first.

∫ x + 1 x² + 4 dx

The derivative of the denominator is:

2x

But the numerator is x + 1. There is no constant k that makes x + 1 = k(2x) for every value of x.

Therefore, this is not a direct f′(x) f(x) integral.

Do not force the pattern

The numerator must be exactly the derivative of the denominator, or a constant multiple of it.

11 • Common mistakes

Watch out for these

  • Forgetting to differentiate the denominator. Always check it before applying the rule.
  • Ignoring a missing constant. If the derivative is 4x but the numerator is x, the missing factor is 4, so the answer needs 1/4.
  • Using the wrong constant. Compare the entire numerator with the entire derivative, not just one term.
  • Forgetting the absolute value. The general formula is ln|f(x)| + C.
  • Forgetting +C. This is still an indefinite integral.
  • Forcing the rule when there is no match. If the numerator is not a constant multiple of the denominator's derivative, use another integration method.

Quick Summary

  1. Look at the denominator and call it f(x).
  2. Differentiate it to find f′(x).
  3. Compare f′(x) with the numerator.
  4. If they match exactly, use ln|f(x)| + C.
  5. If the numerator is a constant multiple of f′(x), keep that constant in front of the logarithm.
  6. If a constant is missing from the numerator, multiply by its reciprocal.
∫ f′(x) f(x) dx = ln|f(x)| + C
