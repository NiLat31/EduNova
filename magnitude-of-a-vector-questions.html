Magnitude of a Vector

Keep in Mind

A vector's magnitude is its length, and it is never negative.

\[ |\vec v|=\sqrt{x^2+y^2} \]
  • Magnitude: Square both components, add them, then take the square root.
  • Quadrants: Use the signs of the horizontal and vertical components to identify the quadrant.
  • Unit vectors: Divide the vector by its magnitude to obtain a vector with magnitude exactly \(1\).
  • Between two points: Subtract the starting coordinates from the destination coordinates.
  • Direction angles: Use degrees and check the quadrant before deciding on the angle.

Remember: a unit vector has magnitude \(1\), but its components do not have to equal \(1\).

Question 01Foundation

Find the magnitude of \(\vec v=3\mathbf i+4\mathbf j\).

Step 1: Square the components and add them.

\[|\vec v|=\sqrt{3^2+4^2}=\sqrt{9+16}=\boxed{5}\]

Question 02Foundation

The points are \(A(2,1)\) and \(B(8,9)\). Find the distance \(AB\).

The horizontal change is \(8-2=6\), and the vertical change is \(9-1=8\).

\[AB=\sqrt{6^2+8^2}=\sqrt{100}=\boxed{10}\]

Question 03Developing

A vector has components \((-5,12)\). What is its magnitude?

A negative component is squared too, so its square is positive.

\[|\vec v|=\sqrt{(-5)^2+12^2}=\sqrt{25+144}=\boxed{13}\]

Question 04Developing

The vector \(\vec v=-8\mathbf i+6\mathbf j\) lies in which quadrant, and what is its magnitude?

The \(x\)-component is negative and the \(y\)-component is positive, so the vector lies in Quadrant II.

\[|\vec v|=\sqrt{(-8)^2+6^2}=\sqrt{100}=\boxed{10}\]

Question 05Intermediate

Find the magnitude of the vector from \(P(-3,4)\) to \(Q(5,-2)\).

\(\overrightarrow{PQ}=(5-(-3),-2-4)=(8,-6)\).

\[|\overrightarrow{PQ}|=\sqrt{8^2+(-6)^2}=\sqrt{100}=\boxed{10}\]

Question 06Intermediate

A vector has magnitude \(17\) and components \((x,8)\), where \(x<0\). Find \(x\).

\[\sqrt{x^2+8^2}=17\Rightarrow x^2+64=289\]

\(x^2=225\), so \(x=\pm15\). Since \(x<0\), \(\boxed{x=-15}\).

Question 07Advanced

For \(\vec v=-24\mathbf i+10\mathbf j\), find the reference angle \(\alpha\) to 1 decimal place.

The reference angle is the acute angle between the vector and the nearest horizontal axis.

\[\alpha=\tan^{-1}\left(\frac{|10|}{|-24|}\right)=\tan^{-1}\left(\frac{10}{24}\right)\approx\boxed{22.6^\circ}\]

The vector's direction angle measured anticlockwise from the positive \(x\)-axis is \(180^\circ-22.6^\circ=157.4^\circ\). That is not the reference angle.

Question 08Advanced

Find the unit vector in the direction of \(\vec v=5\mathbf i-12\mathbf j\).

First, \(|\vec v|=\sqrt{5^2+(-12)^2}=13\).

\[\hat u=\frac{\vec v}{|\vec v|}=\boxed{\frac5{13}\mathbf i-\frac{12}{13}\mathbf j}\]

Question 09Advanced

A vector has direction angle \(210^\circ\) and magnitude \(8\). Which are its components, to 2 decimal places?

Using degree angles, \(x=r\cos\theta\) and \(y=r\sin\theta\).

\[x=8\cos210^\circ\approx-6.93,\quad y=8\sin210^\circ=-4\]

So the components are \(\boxed{(-6.93,-4.00)}\), in Quadrant III.

Question 10Challenge

The vector \(\vec v=a\mathbf i+12\mathbf j\) has magnitude \(13\), with \(a>0\). Find the unit vector in its direction.

\(\sqrt{a^2+12^2}=13\Rightarrow a^2=25\). Since \(a>0\), \(a=5\).

Thus \(\vec v=5\mathbf i+12\mathbf j\), so its unit vector is \(\boxed{\frac5{13}\mathbf i+\frac{12}{13}\mathbf j}\).

Question 11Challenge

A vector \(\vec w\) has magnitude \(1\) and points in the same direction as \( -\frac{12}{13}\mathbf i+\frac5{13}\mathbf j\). Find \(7\vec w\).

The given vector already has magnitude 1, so it is the unit vector \(\vec w\).

\[7\vec w=7\left(-\frac{12}{13}\mathbf i+\frac5{13}\mathbf j\right)=\boxed{-\frac{84}{13}\mathbf i+\frac{35}{13}\mathbf j}\]

Question 12Challenge

A vector has magnitude \(10\) and direction angle \(150^\circ\). Another vector has the same direction but magnitude \(3\). Find the second vector in component form, to 2 decimal places.

For magnitude \(r=3\) and direction angle \(150^\circ\), the components are \(x=r\cos150^\circ\), \(y=r\sin150^\circ\).

\[x=3\left(-\frac{\sqrt3}{2}\right)=-\frac{3\sqrt3}{2}\approx-2.60,\quad y=3\left(\frac12\right)=1.50\]

The answer is \(\boxed{\left(-\frac{3\sqrt3}{2},\frac32\right)}\), equivalent to approximately \((-2.60,1.50)\).
