Magnitude of a Vector

Twenty carefully chosen problems. Follow the clues, watch the signs, and let each calculation earn its answer.

Keep in Mind

These questions test calculations and decisions, not definitions. Keep these tools close:

\[|\vec v|=\sqrt{x^2+y^2}\]
  • Square negative components too. Their squares are positive.
  • For a vector from \(A\) to \(B\), calculate \(B-A\), not \(A-B\).
  • For a unit vector, divide every component by the magnitude.
  • For direction angles, check the quadrant before choosing signs.

A unit vector has magnitude exactly \(1\). Its components do not have to be \(1\).

Question 01Foundation

Find the magnitude of \(\vec v=6\mathbf i-8\mathbf j\).

Square both components, including the negative one:

\[|\vec v|=\sqrt{6^2+(-8)^2}=\sqrt{36+64}=\boxed{10}\]

Question 02Foundation

A vector has components \((-7,24)\). What is its magnitude?

The sign disappears when the component is squared:

\[|\vec v|=\sqrt{(-7)^2+24^2}=\sqrt{49+576}=\boxed{25}\]

Question 03Foundation

Point \(A(-2,5)\) is joined to \(B(4,-3)\). Find the length \(AB\).

Coordinate changes are \(4-(-2)=6\) and \(-3-5=-8\).

\[AB=\sqrt{6^2+(-8)^2}=\sqrt{100}=\boxed{10}\]

Question 04Developing

A vector has magnitude \(13\) and components \((x,12)\), where \(x<0\). Find \(x\).

\[\sqrt{x^2+12^2}=13\Rightarrow x^2+144=169\Rightarrow x^2=25\]

Thus \(x=\pm5\). Since \(x<0\), the answer is \(\boxed{-5}\).

Question 05Developing

The vector \(\vec v=-9\mathbf i-12\mathbf j\) points into which quadrant, and what is its magnitude?

Both components are negative, so the vector is in Quadrant III.

\[|\vec v|=\sqrt{(-9)^2+(-12)^2}=\sqrt{225}=\boxed{15}\]

Question 06Developing

A vector has components \((x,-8)\), magnitude \(17\), and \(x>0\). Find \(x\).

\[x^2+(-8)^2=17^2\Rightarrow x^2=289-64=225\]

So \(x=\pm15\). The condition \(x>0\) gives \(\boxed{x=15}\).

Question 07Intermediate

Find the magnitude of \(\vec v=-20\mathbf i+21\mathbf j\).

\[|\vec v|=\sqrt{(-20)^2+21^2}=\sqrt{400+441}=\sqrt{841}=\boxed{29}\]

Question 08Intermediate

Find the unit vector in the direction of \(\vec v=8\mathbf i-15\mathbf j\).

The magnitude is \(\sqrt{8^2+(-15)^2}=17\).

\[\hat u=\frac{\vec v}{|\vec v|}=\boxed{\frac8{17}\mathbf i-\frac{15}{17}\mathbf j}\]

Question 09Intermediate

A vector is \((-6,8)\). Which option gives its unit vector?

The magnitude is \(10\), so divide both components by \(10\):

\[\hat u=\left(-\frac6{10},\frac8{10}\right)=\boxed{\left(-\frac35,\frac45\right)}\]

Question 10Intermediate

A vector has components \((2k,k)\) and magnitude \(5\sqrt5\), where \(k>0\). Find \(k\).

\[\sqrt{(2k)^2+k^2}=\sqrt{5k^2}=k\sqrt5\quad(k>0)\]

Since \(k\sqrt5=5\sqrt5\), \(\boxed{k=5}\).

Question 11Advanced

A vector has magnitude \(6\) and direction angle \(330^\circ\). Find its components to 2 decimal places.

\[x=6\cos330^\circ=3\sqrt3\approx5.20,\quad y=6\sin330^\circ=-3\]

The angle is in Quadrant IV, so \(x>0\) and \(y<0\). Answer: \(\boxed{(5.20,-3.00)}\).

Question 12Advanced

A vector has magnitude \(4\) and direction angle \(135^\circ\). Find its exact components.

\(\cos135^\circ=-\frac{\sqrt2}{2}\) and \(\sin135^\circ=\frac{\sqrt2}{2}\).

\[(x,y)=\left(4\cos135^\circ,4\sin135^\circ\right)=\boxed{(-2\sqrt2,2\sqrt2)}\]

Question 13Advanced

A vector has magnitude \(10\) and direction angle \(240^\circ\). Which components are correct?

\(\cos240^\circ=-\frac12\) and \(\sin240^\circ=-\frac{\sqrt3}{2}\).

\[(x,y)=\left(10\cos240^\circ,10\sin240^\circ\right)=\boxed{(-5,-5\sqrt3)}\]

Question 14Advanced

For \(A(1,-4)\) and \(B(-5,4)\), find the unit vector in the direction from \(A\) to \(B\).

\(\overrightarrow{AB}=(-5-1,4-(-4))=(-6,8)\), whose magnitude is \(10\).

\[\hat u=\frac1{10}(-6,8)=\boxed{\left(-\frac35,\frac45\right)}\]

Question 15Advanced

The vector \(\vec v=(3k,4k)\) has magnitude \(25\), with \(k>0\). Find \(k\).

\[|\vec v|=\sqrt{9k^2+16k^2}=5|k|\]

Since \(k>0\), \(5k=25\), so \(\boxed{k=5}\).

Question 16Advanced

The vector \(\vec v=(-5,y)\) has magnitude \(13\), and \(y>0\). Find \(y\).

\[(-5)^2+y^2=13^2\Rightarrow y^2=169-25=144\]

Since \(y>0\), \(\boxed{y=12}\).

Question 17Challenge

A vector has magnitude \(13\), horizontal component \(-5\), and lies above the \(x\)-axis. What is the vector?

\[(-5)^2+y^2=13^2\Rightarrow y^2=144\Rightarrow y=\pm12\]

Above the \(x\)-axis means \(y>0\), so \(\boxed{\vec v=-5\mathbf i+12\mathbf j}\).

Question 18Challenge

Given \(\vec v=-8\mathbf i+15\mathbf j\), find \(3\vec v\) and its magnitude.

\(3\vec v=-24\mathbf i+45\mathbf j\). The original magnitude is \(\sqrt{64+225}=17\).

Multiplying a vector by \(3\) multiplies its magnitude by \(3\), so \(|3\vec v|=3(17)=\boxed{51}\).

Question 19Challenge

Find the distance between \(P(3,7)\) and \(Q(-1,-5)\).

The coordinate changes are \(-1-3=-4\) and \(-5-7=-12\).

\[PQ=\sqrt{(-4)^2+(-12)^2}=\sqrt{160}=\boxed{4\sqrt{10}}\]

Question 20Challenge

A vector has magnitude \(12\) and direction angle \(150^\circ\). A second vector points in the same direction but has magnitude \(5\). Find the second vector's components, to 2 decimal places.

Same direction means the second vector has direction angle \(150^\circ\) too. Use its magnitude \(5\):

\[x=5\cos150^\circ=-\frac{5\sqrt3}{2}\approx-4.33,\quad y=5\sin150^\circ=2.50\]

So the answer is \(\boxed{(-4.33,2.50)}\).
