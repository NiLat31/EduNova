Integration Using Trigonometrical Relationships

Discover how familiar trigonometric differentiation rules lead directly to their integration formulas.

∫ θ π

Where Do These Integration Rules Come From?

You may have already seen formulas such as the integral of sec 2 x or sin x .

It can be tempting to memorize these formulas and use them whenever they appear. But there is a much better question to ask:

Ask yourself:

“What function would give me this expression when I differentiate it?”

This is because integration and differentiation are closely connected. Integration can undo differentiation.

Integration Undoes Differentiation

Think of differentiation and integration as opposite processes. Differentiation takes a function and finds its derivative. Integration works backwards and finds a function whose derivative is the expression we started with.

Differentiation followed by integration
∫ d dx [ f ( x ) ] dx = f ( x ) + C
Integration followed by differentiation
d dx [ ∫ f ( x ) dx ] = f ( x )
Why is there a +C? Differentiating a constant gives zero. Therefore, differentiation cannot tell us which constant was originally present. When we integrate, we include +C to represent any constant.
See the idea in action

Start with a function:

f ( x ) = x 3

Differentiate it:

d dx ( x 3 ) = 3 x 2

Now integrate the result:

∫ 3 x 2 dx = x 3 + C

A Quick Differentiation Reminder

Since we are going to work backwards from differentiation, let's remind ourselves of the trigonometric derivatives we need.

Sine: d dx ( sinx ) = cosx
Cosine: d dx ( cosx ) = − sinx
Tangent: d dx ( tanx ) = sec 2 x
Cotangent: d dx ( ln | sinx | ) = cotx

1. Integrating sec²x

Let's begin with one of the most direct examples. We want to find:

∫ sec 2 x dx

Instead of trying to remember the answer, ask:

What differentiates to sec²x? From differentiation: d dx ( tanx ) = sec 2 x
Derivation

We know:

d dx ( tanx ) = sec 2 x

Integration reverses this differentiation:

∫ sec 2 x dx = tanx + C
Result
∫ sec 2 x dx = tanx + C

What If We Have ax?

Now suppose the angle is not simply x , but ax .

We want to find:

∫ sec 2 ( ax ) dx
Deriving the 1/a

Start with the function:

tan ( ax )

Differentiate using the chain rule:

d dx [ tan ( ax ) ] = a sec 2 ( ax )

We need only sec 2 (ax) , but differentiation produced an extra a .

Divide by a to remove that extra factor:

1 a d dx [ tan ( ax ) ] = sec 2 ( ax )

Therefore:

∫ sec 2 ( ax ) dx = 1 a tan ( ax ) + C
Why does 1/a appear? Because differentiating a function containing ax produces an extra factor of a . The 1a cancels it.

2. Integrating cot x

For cotx , we again work backwards from differentiation.

Derivation

Start with:

ln | sinx |

Differentiate it:

d dx [ ln | sinx | ] = cosx sinx

Since cosx sinx is cotx :

d dx [ ln | sinx | ] = cotx
∫ cotx dx = ln | sinx | + C
Result
∫ cotx dx = ln | sinx | + C

3. Integrating cosec²x

Now use the same reverse-thinking method.

Ask: What differentiates to cosec 2 x with the correct sign?
Derivation

We know:

d dx ( cotx ) = − cosec 2 x

Our integral contains positive cosec 2 x , so we need a negative sign:

d dx ( − cotx ) = cosec 2 x
∫ cosec 2 x dx = − cotx + C
Result
∫ cosec 2 x dx = − cotx + C

4. Integrating sin x cos x

This time, the integrand contains two trigonometric functions multiplied together.

∫ sinx cosx dx

We can use the double-angle identity to turn the product into a single trigonometric function.

Remember

The double-angle formula for sine is:

sin ( 2x ) = 2 sinx cosx

Therefore:

sinx cosx = 1 2 sin ( 2x )
Derivation
∫ sinx cosx dx

Replace sinx cosx using the double-angle identity:

= ∫ 1 2 sin ( 2x ) dx
= 1 2 ∫ sin ( 2x ) dx

Since the angle is 2x , integration introduces another factor of 12 :

= 1 2 ( − 1 2 cos ( 2x ) ) + C
= − 1 4 cos ( 2x ) + C
Result
∫ sinx cosx dx = − 1 4 cos ( 2x ) + C

Reminder: Double-Angle Formulas

The next two integrals involve sin2x and cos2x . These cannot be integrated using the ordinary power rule.

We first rewrite them using double-angle identities.

Sine Double-Angle Relationship

sin ( 2x ) = 2 sinx cosx

Cosine Double-Angle Relationship

cos ( 2x ) = cos 2 x − sin 2 x

Combining this with sin2 x + cos2 x = 1 gives:

cos 2 x = 1 2 [ 1 + cos ( 2x ) ] sin 2 x = 1 2 [ 1 − cos ( 2x ) ]

5. Integrating cos²x

∫ cos 2 x dx
Step-by-step derivation

Start with the double-angle identity:

cos 2 x = 1 2 [ 1 + cos ( 2x ) ]

Substitute it into the integral:

∫ cos 2 x dx = ∫ 1 2 [ 1 + cos ( 2x ) ] dx

Separate the terms:

= 1 2 ∫ 1 dx + 1 2 ∫ cos ( 2x ) dx

Integrate each term:

= x 2 + 1 2 ( 1 2 sin ( 2x ) ) + C

Simplify:

= x 2 + 1 4 sin ( 2x ) + C
Result
∫ cos 2 x dx = x 2 + 1 4 sin ( 2x ) + C

6. Integrating sin²x

∫ sin 2 x dx
Step-by-step derivation

Use the double-angle identity:

sin 2 x = 1 2 [ 1 − cos ( 2x ) ]

Substitute:

∫ sin 2 x dx = ∫ 1 2 [ 1 − cos ( 2x ) ] dx

Separate the terms:

= 1 2 ∫ 1 dx − 1 2 ∫ cos ( 2x ) dx

Integrate:

= x 2 − 1 2 ( 1 2 sin ( 2x ) ) + C

Simplify:

= x 2 − 1 4 sin ( 2x ) + C
Result
∫ sin 2 x dx = x 2 − 1 4 sin ( 2x ) + C

All the Relationships Together

Secant squared: ∫ sec 2 (ax) dx = 1 a tan (ax) + C
Cotangent: ∫ cot (ax) dx = 1 a ln | sin (ax) | + C
Cosecant squared: ∫ cosec 2 (ax) dx = − 1 a cot (ax) + C
Sine × cosine: ∫ sinx cosx dx = − 1 4 cos (2x) + C
Cosine squared: ∫ cos 2 x dx = x 2 + 1 4 sin (2x) + C
Sine squared: ∫ sin 2 x dx = x 2 − 1 4 sin (2x) + C
