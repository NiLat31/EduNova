02 • VECTOR ADDITION

Adding vectors

To move from A to C, we can travel from A to B and then from B to C. The two vectors join head-to-tail.

\[ \overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC} \] Therefore, \[ \boxed{ \mathbf a+\mathbf x = \overrightarrow{AC} } \]
Build the resultant
Click the stages
Start with the first vector.
Worked Example 1
GIVEN
\[ \overrightarrow{AB}=\mathbf a \qquad \overrightarrow{BC}=\mathbf x \]
FIND
\[ \overrightarrow{AC} \]
SOLUTION
Follow A → B → C: \[ \overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC} \] Therefore, \[ \boxed{ \overrightarrow{AC} = \mathbf a+\mathbf x } \]
03 • VECTOR SUBTRACTION

Subtracting vectors

Subtraction is closely connected to direction. Reversing a vector changes its sign.

Reverse the vector
Click the button
\( \overrightarrow{BC}=\mathbf x \)
\[ \overrightarrow{CB} = -\overrightarrow{BC} = -\mathbf x \]
Worked Example 2
GIVEN
\[ \overrightarrow{AB}=\mathbf a \qquad \overrightarrow{BC}=\mathbf x \]
FIND
\[ \overrightarrow{CA} \]
SOLUTION
From C to A we travel backwards: \[ \overrightarrow{CB}=-\mathbf x \] and \[ \overrightarrow{BA}=-\mathbf a \] Therefore, \[ \boxed{ \overrightarrow{CA} = -\mathbf x-\mathbf a } \]
04 • MIDPOINT

Finding the midpoint

A midpoint divides a vector into two equal parts. Drag A or B and the midpoint M will automatically stay exactly halfway between them.

Interactive midpoint
Drag A or B
M is halfway between A and B.
Capital-letter form \[ \boxed{ \overrightarrow{AM} = \frac12 \overrightarrow{AB} } \]
Small-letter form If \[ \overrightarrow{AB}=\mathbf a, \] then \[ \boxed{ \overrightarrow{AM} = \frac12\mathbf a } \]
Worked Example 3
GIVEN
M is the midpoint of AB and \[ \overrightarrow{AB}=\mathbf a. \]
SOLUTION
Since M is halfway along AB, \[ \overrightarrow{AM} = \frac12 \overrightarrow{AB} \]
ANSWER
\[ \boxed{ \overrightarrow{AM} = \frac12\mathbf a } \]
05 • RATIOS

Dividing a vector in a ratio

A ratio tells us how the journey from A to B is split. If L divides AB in the ratio 1:4, there are five equal parts altogether.

Interactive ratio division
Change the ratio
The ratio is \(1:4\).
What does the first number mean?

In \(1:4\), the first number tells us that AL contains 1 equal part.

\[ AL=\frac15AB \]
What does the second number mean?

The second number tells us that LB contains 4 equal parts.

\[ LB=\frac45AB \]
The total number of equal parts is \[ 1+4=5. \] Therefore, \[ \boxed{ \overrightarrow{AL} = \frac15 \overrightarrow{AB} } \]
Worked Example 4
QUESTION
L divides AB in the ratio \(1:4\). If \[ \overrightarrow{AB}=\mathbf a, \] find \[ \overrightarrow{AL}. \]
STEP 1
Add the two ratio parts: \[ 1+4=5 \]
STEP 2
AL contains one of the five equal parts: \[ \overrightarrow{AL} = \frac15 \overrightarrow{AB} \]
STEP 3
Since \[ \overrightarrow{AB}=\mathbf a, \] therefore \[ \boxed{ \overrightarrow{AL} = \frac15\mathbf a } \]
06 • RATIO IN VECTOR FORM

Another ratio example

The same idea works for any positive ratio. The important step is always to find the total number of equal parts first.

Worked Example 5
QUESTION
P divides AB in the ratio \(2:3\). If \[ \overrightarrow{AB}=\mathbf b, \] find \[ \overrightarrow{AP}. \]
STEP 1
Total parts: \[ 2+3=5 \]
STEP 2
AP contains 2 of the 5 equal parts: \[ \overrightarrow{AP} = \frac25 \overrightarrow{AB} \]
ANSWER
\[ \boxed{ \overrightarrow{AP} = \frac25\mathbf b } \]
07 • SUMMARY

Vector geometry toolkit

Parallelogram Opposite sides have equal vectors when their directions match. \[ \overrightarrow{AB} = \overrightarrow{DC} \]
Addition Follow a route from one point to another. \[ \overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC} \]
Midpoint Half of the original vector: \[ \overrightarrow{AM} = \frac12 \overrightarrow{AB} \]
Ratio Add the ratio numbers to find the total parts. \[ m:n \Rightarrow m+n \text{ total parts} \]
