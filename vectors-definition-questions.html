Definition of Vectors.

Test your understanding of magnitude, direction, vector notation, vector addition, components, and parallel vectors through a carefully structured set of questions.

Keep in mind.
  • A vector is a quantity that has both magnitude and direction. The magnitude tells us the size or length of the vector, while the direction tells us which way the vector points.
  • A vector can be represented using an arrow. The length of the arrow represents its magnitude, while the arrowhead shows its direction.
  • Two vectors are equal only when they have the same magnitude and the same direction. Their positions on a diagram do not need to be the same.
  • Reversing a vector changes its direction. Therefore, \(\overrightarrow{AB}\) and \(\overrightarrow{BA}\) have the same magnitude but point in opposite directions.
  • A vector and its opposite have the same magnitude but opposite directions. For example, a vector pointing east and another pointing west may have the same length but are not equal.
  • When a vector is written in component form, \((x,y)\), the first component represents the horizontal movement and the second component represents the vertical movement.
  • A positive horizontal component represents movement to the right, while a negative horizontal component represents movement to the left.
  • A positive vertical component represents movement upward, while a negative vertical component represents movement downward.
  • When adding vectors, always add their corresponding components. Add horizontal components together and vertical components together.
  • Remember that parallel vectors do not have to be equal. Parallel vectors can have different magnitudes, as long as they point in the same or opposite directions.
