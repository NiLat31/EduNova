The Trapezium Rule

Learn how the area under a curve can be estimated by dividing the interval into equal parts and replacing sections of the curve with straight lines.

Introduction

Definite integration allows us to find the exact area between a curve and the x-axis. However, sometimes a function is difficult to integrate exactly, or we may only have a collection of values rather than an equation.

In these situations, we can estimate the area using the Trapezium Rule.

The main idea is to divide the interval into equal sections, replace each curved section with a straight line, calculate the resulting trapezium areas, and add them together.

Estimating the Area

Consider the area under a curve between x = a and x = b.

If the curve is not a simple geometric shape, finding its exact area may require integration.

Instead, we divide the region into smaller pieces. When the pieces are sufficiently narrow, the curved boundary can be approximated by straight lines.

Key idea A collection of trapezia can be used to approximate the area under a curve.

The Curve and the Intervals

Suppose the interval from a to b is divided into equal intervals.

Let the width of every interval be h.

The points on the curve can then be labelled:

x₀, x₁, x₂, x₃, ... , xₙ

Their corresponding y-values are:

y₀, y₁, y₂, y₃, ... , yₙ

Replacing the Curve

Between two consecutive points, (x₀, y₀) and (x₁, y₁), the curve is replaced by a straight line.

This creates a trapezium whose parallel sides have lengths y₀ and y₁.

The perpendicular distance between these parallel sides is the interval width h.

Area of trapezium = 1 2 × (sum of parallel sides) × (perpendicular distance)

A Series of Trapezia

Instead of using one trapezium, we can divide the whole interval into several equal sections.

Each section produces one trapezium. The total estimated area is found by adding the areas of all the trapezia.

Total area ≈ Area₁ + Area₂ + Area₃ + ... + Areaₙ
Important observation When neighbouring trapezia are joined, each interior y-value belongs to two trapezia. This is why the interior values are multiplied by 2 in the final formula.

Why Is It an Approximation?

The original boundary is curved, while the Trapezium Rule replaces sections of the curve with straight lines.

Therefore, the trapezia do not usually have exactly the same area as the region under the curve.

However, if we increase the number of intervals, each interval becomes narrower.

The straight-line segments then follow the curve more closely, making the estimated area closer to the exact area.

The main idea More intervals → narrower trapezia → closer approximation.

Deriving the Trapezium Rule

We can derive the Trapezium Rule by adding the areas of the trapezia one at a time.

1. One Trapezium

Consider the first trapezium, formed between the points (x₀, y₀) and (x₁, y₁).

Its parallel sides have lengths y₀ and y₁, while its perpendicular distance is h.

Recall that the area of a trapezium is:

Area = 1 2 × (sum of parallel sides) × (perpendicular distance)

Therefore:

A₁ = 1 2 × (y₀ + y₁) × h

Rearranging the factors:

A₁ = h 2 (y₀ + y₁)

2. Two Trapezia

Now consider the second trapezium, formed between (x₁, y₁) and (x₂, y₂).

A₂ = h 2 (y₁ + y₂)

The total estimated area of the first two trapezia is:

A ≈ A₁ + A₂

Substitute the expressions for A₁ and A₂:

A ≈ h 2 (y₀ + y₁) + h 2 (y₁ + y₂)

Factor out the common factor h/2:

A ≈ h 2 [(y₀ + y₁) + (y₁ + y₂)]

Expand the brackets:

A ≈ h 2 [y₀ + y₁ + y₁ + y₂]

Combine the two y₁ terms:

y₁ + y₁ = 2y₁
A ≈ h 2 (y₀ + 2y₁ + y₂)

3. Three Trapezia

Add a third trapezium between (x₂, y₂) and (x₃, y₃).

Its area is:

A₃ = h 2 (y₂ + y₃)

Therefore:

A ≈ h 2 (y₀ + 2y₁ + y₂) + h 2 (y₂ + y₃)

Factor out h/2:

A ≈ h 2 [y₀ + 2y₁ + y₂ + y₂ + y₃]

Combine the two y₂ terms:

y₂ + y₂ = 2y₂
A ≈ h 2 (y₀ + 2y₁ + 2y₂ + y₃)

4. Extending to n Trapezia

If we continue adding trapezia until we reach xₙ = b, there will be n trapezia.

The first and last y-values occur once. Every interior y-value occurs twice because each interior point belongs to two neighbouring trapezia.

A ≈ h 2 [y₀ + 2y₁ + 2y₂ + ... + 2yₙ₋₁ + yₙ]

Grouping the interior terms:

A ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]
b ∫ a f(x) dx
∫ a b f ( x ) dx

Since the Trapezium Rule normally gives an estimate, we use the approximation symbol ≈.

b ∫ a f(x) dx ≈ ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]

6. Finding h

The total width of the interval from a to b is:

b − a

This entire interval is divided into n equal intervals.

Therefore, the width of each interval is:

h = b − a n

Common Mistakes

01. Forgetting to find h

Always calculate h = (b − a)/n before applying the formula.

02. Doubling the wrong terms

Only the interior y-values are multiplied by 2. The first and last values are used once.

03. Confusing points and intervals

If there are n intervals, there are n + 1 points.

04. Using = instead of ≈

The Trapezium Rule normally produces an approximation, so use ≈.

∫ a b f ( x ) dx f(x) dx ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]

where h = (b − a)/n and n is the number of equal intervals.
