The Trapezium Rule

Learn how the area under a curve can be estimated by dividing the interval into equal parts and replacing sections of the curve with trapezia.

Introduction

Definite integration allows us to find the exact area between a curve and the x-axis. However, sometimes the function is difficult to integrate exactly, or we may only have a set of values rather than an equation.

In these situations, we can estimate the area using the Trapezium Rule.

The main idea is simple: divide the interval into equal sections, replace each part of the curve with a straight line, calculate the resulting trapezium areas, and add them together.

Estimating the Area

Consider the area under a curve between x = a and x = b.

If the curve is not a simple shape, finding its exact area may require integration.

Instead, we can divide the region into smaller pieces. If the pieces are sufficiently narrow, the curved boundary can be approximated by straight lines.

Key idea A collection of trapezia can be used to approximate the area under a curve.

The Curve and the Intervals

Suppose the interval from a to b is divided into equal intervals.

Let the width of every interval be h.

The points on the curve can then be labelled:

x₀, x₁, x₂, x₃, ... , xₙ

Their corresponding y-values are:

y₀, y₁, y₂, y₃, ... , yₙ

The red straight-line segments form the trapezium approximation.

Replacing the Curve

Between two consecutive points, (x₀, y₀) and (x₁, y₁), the curve is replaced by a straight line.

This creates a trapezium whose parallel sides have lengths y₀ and y₁.

The perpendicular distance between these parallel sides is the interval width h.

Area of trapezium = 1 2 × (sum of parallel sides) × (perpendicular distance)

A Series of Trapezia

Instead of using just one trapezium, we can divide the whole interval into several equal sections.

Each section produces one trapezium. The total estimated area is found by adding all of their areas.

Total area ≈ Area₁ + Area₂ + Area₃ + ... + Areaₙ
Important observation When neighbouring trapezia are joined, the interior y-values belong to two trapezia. This is why the interior values are multiplied by 2 in the final formula.

Why Is It an Approximation?

The original boundary is curved, while the Trapezium Rule replaces sections of that curve with straight lines.

Therefore, the trapezia do not usually have exactly the same area as the region under the curve.

However, if we increase the number of intervals, each interval becomes narrower.

The straight-line segments then follow the curve more closely, making the estimated area closer to the exact area.

The main idea More intervals → narrower trapezia → closer approximation.

Deriving the Trapezium Rule

We can now derive the Trapezium Rule by adding the areas of the trapezia one at a time.

1. One Trapezium

Consider the first trapezium, formed between the points (x₀, y₀) and (x₁, y₁).

Its parallel sides have lengths y₀ and y₁, while its perpendicular distance is h.

Recall that the area of a trapezium is:

Area = 1 2 × (sum of parallel sides) × (perpendicular distance)

Therefore:

A₁ = 1 2 × (y₀ + y₁) × h

Rearranging the factors gives:

A₁ = h 2 (y₀ + y₁)

2. Two Trapezia

Now consider the second trapezium, formed between (x₁, y₁) and (x₂, y₂).

Its parallel sides are y₁ and y₂, and its width is again h.

A₂ = h 2 (y₁ + y₂)

The total estimated area of the first two trapezia is:

A ≈ A₁ + A₂

Substitute the expressions for A₁ and A₂:

A ≈ h 2 (y₀ + y₁) + h 2 (y₁ + y₂)

Both terms contain the common factor h/2.

Therefore, factor h/2 out:

A ≈ h 2 [(y₀ + y₁) + (y₁ + y₂)]

Expand the brackets:

A ≈ h 2 [y₀ + y₁ + y₁ + y₂]

There are two y₁ terms:

y₁ + y₁ = 2y₁

Therefore:

A ≈ h 2 (y₀ + 2y₁ + y₂)
Notice the pattern The first and last y-values appear once, while the middle y-value appears twice.

3. Three Trapezia

Now add a third trapezium between (x₂, y₂) and (x₃, y₃).

Its area is:

A₃ = h 2 (y₂ + y₃)

From the previous result, the area of the first two trapezia is:

A₁ + A₂ = h 2 (y₀ + 2y₁ + y₂)

Therefore:

A ≈ h 2 (y₀ + 2y₁ + y₂) + h 2 (y₂ + y₃)

Factor out the common factor h/2:

A ≈ h 2 [y₀ + 2y₁ + y₂ + y₂ + y₃]

The two y₂ terms combine:

y₂ + y₂ = 2y₂

Therefore:

A ≈ h 2 (y₀ + 2y₁ + 2y₂ + y₃)

4. Extending to n Trapezia

If we continue adding trapezia until we reach xₙ = b, there will be n trapezia.

The first and last y-values occur only once. Every y-value between them occurs twice because each interior point belongs to two neighbouring trapezia.

Therefore, the total estimated area is:

A ≈ h 2 [y₀ + 2y₁ + 2y₂ + ... + 2yₙ₋₁ + yₙ]

We can group all the interior terms together:

A ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]

5. Connecting the Area to Integration

The exact area under a curve from x = a to x = b is represented by the definite integral:

∫ b a f(x) dx

The Trapezium Rule does not normally give the exact area. It gives an estimate.

Therefore, we use the approximation symbol ≈.

Substituting the trapezium expression gives:

∫ b a f(x) dx ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]

6. Finding h

The complete interval extends from a to b.

Therefore, its total width is:

b − a

This entire interval is divided into n equal intervals.

Therefore, each interval has width:

h = b − a n

This value of h can then be substituted into the Trapezium Rule.

Worked Example

Example

Use the Trapezium Rule with four equal intervals to estimate:

∫ 4 0 f(x) dx

Suppose the corresponding values of f(x) are:

y₀ = 2,   y₁ = 3,   y₂ = 5,   y₃ = 4,   y₄ = 7
Step 1: Find n

There are four equal intervals, so:

n = 4
Step 2: Find h

Use:

h = b − a n

Substitute:

h = 4 − 0 4
h = 4 4
h = 1
Step 3: Write the Trapezium Rule
A ≈ h 2 [y₀ + y₄ + 2(y₁ + y₂ + y₃)]
Step 4: Substitute the values
A ≈ 1 2 [2 + 7 + 2(3 + 5 + 4)]
Step 5: Simplify inside the brackets
3 + 5 + 4 = 12
2(12) = 24
2 + 7 + 24 = 33
Step 6: Final calculation
A ≈ 1 2 × 33
A ≈ 16.5

Common Mistakes

01. Forgetting to find h

Always calculate h = (b − a)/n before using the formula.

02. Doubling the wrong terms

Only the interior y-values are multiplied by 2. The first and last values are used once.

03. Using n + 1 as the number of intervals

If there are n intervals, there are n + 1 points.

04. Using = instead of ≈

The Trapezium Rule normally produces an approximation, so use ≈.

The Trapezium Rule

∫ b a f(x) dx ≈ h 2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]

where h = (b − a)/n and n is the number of equal intervals.
