Recognize Integrals

Before you integrate, learn to recognize the form of the function and choose the rule that matches it.

Recognize Before You Integrate

Integration is the reverse process of differentiation. This means that many integration rules can be understood by asking one simple question:

What function would give me this when I differentiate?

Once you recognize the pattern, the correct integration rule becomes much easier to choose.

Keep in mind

Do not start integrating immediately. First look at the function and identify its form.

1. Rules You Already Know

Start with the familiar integration rules. These are the patterns you should recognize quickly.

Power of x

∫ x n dx = x n + 1 n + 1 + C

where n ≠ −1.

Worked Example

Integrate x⁴

∫ x 4 dx
= x 5 5 + C

Constant

∫ a dx = ax + C

A power of (ax + b)

∫ ( ax + b ) n dx = ( ax + b ) n + 1 a ( n + 1 ) + C

where n ≠ −1.

2. Recognizing eax

When you see an exponential function of the form eax, remember that differentiating it produces an extra factor of a.

∫ e ax dx = 1 a e ax + C

Why do we divide by a?

Because differentiation of eax gives:

d dx e ax = a e ax

Integration must therefore divide by a to cancel that extra factor.

Worked Example

Integrate e3x

∫ e 3x dx = 1 3 e 3x + C

3. Recognizing sin(ax) and cos(ax)

The trigonometric functions have a repeating pattern when differentiated. Your teacher's circle gives us a very useful way to remember it.

The rule to remember

For differentiation, move clockwise.

For integration, move anti-clockwise.

Integrating cos(ax)

∫ cos ( ax ) dx = 1 a sin ( ax ) + C
Worked Example

Integrate cos(4x)

∫ cos ( 4x ) dx = 1 4 sin ( 4x ) + C

Integrating sin(ax)

∫ sin ( ax ) dx = − 1 a cos ( ax ) + C
Worked Example

Integrate sin(5x)

∫ sin ( 5x ) dx = − 1 5 cos ( 5x ) + C

4. Recognizing 1/x

The function 1/x is a special case. Although it can be written as x−1, we cannot use the ordinary power rule.

∫ 1 x dx = ln | x | + C

Why is it different?

If n = −1 in the power rule, then:

n + 1 = − 1 + 1 = 0

This would require division by zero, so the power rule cannot be used.

Therefore, 1/x has its own rule: ln|x| + C.

5. Recognizing a/(bx + d)

This form looks more complicated, but it is closely related to the integral of 1/x.

∫ a bx + d dx = a b ln | bx + d | + C

Why do we divide by b?

When we differentiate ln|bx + d|, the derivative of the inside, bx + d, is b.

Therefore, the integration answer needs a factor of 1/b to cancel it.

Worked Example

Integrate 5 2x + 3

∫ 5 2x + 3 dx
= 5 2 ln | 2x + 3 | + C

7. Common Recognition Mistakes

Forgetting the coefficient inside the function

For example, when integrating cos(3x), you must include the factor 1/3.

Forgetting the negative sign with sin

Integration moves anti-clockwise, so sin(ax) becomes −cos(ax).

Using the power rule for 1/x

1/x is the special case where n = −1. Its integral is ln|x| + C.

Forgetting the coefficient of the inside

If the inside is ax + b, remember that differentiating it gives a.

Recognize First

The most important skill in this topic is identifying the pattern before you integrate.

x n → x n + 1 n + 1 + C
e ax → 1 a e ax + C
1 x → ln | x | + C
