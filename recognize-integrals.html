Recognize Integrals

Learn how to recognize common functions and choose the correct integration rule before doing any calculations.

Introduction

Before integrating a function, it is important to recognize what type of function you are looking at.

Some integrals follow familiar rules. Once you recognize the form of the function, you can apply the correct rule directly.

Keep in mind Recognition comes first. Look at the function carefully before choosing an integration rule.

Basic Integration Rules

Start with these important rules.

Power Rule
∫ x n dx = x n + 1 n + 1 + C

where n ≠ −1

Constant Rule
∫ a dx = a x + C
Linear Function Raised to a Power
∫ ( a x + b ) n dx = ( a x + b ) n + 1 a ( n + 1 ) + C

where n ≠ −1

Recognizing e a x

If the function contains an exponential term of the form e a x , use the following rule.

∫ e a x dx = 1 a e a x + C
Worked Example

Find:

∫ e 3 x dx

Here, a=3.

= 1 3 e 3 x + C

Common Trigonometric Rules

Cosine
∫ cos ( a x ) dx = 1 a sin ( a x ) + C
Sine
∫ sin ( a x ) dx = − 1 a cos ( a x ) + C
Worked Example

Find:

∫ sin ( 4 x ) dx

The function is sine, so integration moves anti-clockwise from sin x to − cos x .

= − 1 4 cos ( 4 x ) + C

Recognizing 1 x

The function 1 x is a special case. We cannot use the ordinary power rule because its power is n = − 1 .

Special Rule
∫ 1 x dx = ln | x | + C
Worked Example

Find:

∫ 1 x dx
= ln | x | + C

Recognizing a b x + d

Another important form is a constant divided by a linear expression.

Linear Denominator Rule
∫ a b x + d dx = a b ln | b x + d | + C
Worked Example

Find:

∫ 6 2 x + 5 dx

Here:

a = 6 , b = 2

Therefore:

= 6 2 ln | 2 x + 5 | + C
= 3 ln | 2 x + 5 | + C

How to Recognize the Form

Function Recognize it as Use
e a x Exponential Exponential rule
cos ( a x ) Cosine Trigonometric rule
sin ( a x ) Sine Trigonometric rule
1 x Reciprocal of x Natural logarithm rule
a b x + d Constant over linear function Logarithm rule

Common Mistakes

1. Forgetting the extra factor.

When integrating e a x , sin ( a x ) , or cos ( a x ) , remember the factor 1 a .

2. Using the power rule for 1 x .

The power rule does not work when n = − 1 . Use the logarithm rule instead.

3. Forgetting \(+C\).

Always include the constant of integration when finding an indefinite integral.

Lesson Summary

Power: ∫ x n dx = x n + 1 n + 1 + C
Exponential: ∫ e a x dx = 1 a e a x + C
Sine: ∫ sin ( a x ) dx = − 1 a cos ( a x ) + C
Cosine: ∫ cos ( a x ) dx = 1 a sin ( a x ) + C
Reciprocal: ∫ 1 x dx = ln | x | + C
