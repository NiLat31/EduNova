Before You Integrate

Before integrating a function, it is important to recognize what type of function you are looking at.

Some integrals follow familiar rules. Once you recognize the form of the function, you can apply the correct rule directly.

Keep in mind Recognition comes first. Look at the function carefully before choosing an integration rule.

Basic Integration Rules

These are some of the most important integration rules. Recognizing their forms will help you decide which rule to use.

Power Rule
\[ \int x^n\,dx = \frac{x^{n+1}}{n+1}+C \]

Where \(n\neq -1\).

Constant Rule
\[ \int a\,dx=ax+C \]
Linear Function Raised to a Power
\[ \int (ax+b)^n\,dx = \frac{(ax+b)^{n+1}}{a(n+1)}+C \]

Where \(n\neq -1\).

Recognizing Exponential Integrals

When you see an exponential function with base \(e\), such as \(e^{ax}\), you can recognize it using the exponential integration rule.

Exponential Rule
\[ \int e^{ax}\,dx = \frac{1}{a}e^{ax}+C \]
Worked Example

Evaluate:

\[ \int e^{3x}\,dx \]
**Step 1: Recognize the function**

The function is an exponential function with \(a=3\).

**Step 2: Apply the rule** \[ \int e^{3x}\,dx = \frac{1}{3}e^{3x}+C \]
**Final Answer** \[ \boxed{\frac{1}{3}e^{3x}+C} \]

Trigonometric Integration Rules

When integrating cosine or sine functions with a coefficient inside the angle, remember to include the extra factor.

Cosine Rule
\[ \int \cos(ax)\,dx = \frac{1}{a}\sin(ax)+C \]
Sine Rule
\[ \int \sin(ax)\,dx = -\frac{1}{a}\cos(ax)+C \]
Worked Example

Evaluate:

\[ \int \sin(4x)\,dx \]
**Step 1: Recognize the function**

The function is sine, and the coefficient of \(x\) is \(4\).

**Step 2: Apply the sine integration rule** \[ \int \sin(4x)\,dx = -\frac{1}{4}\cos(4x)+C \]
**Final Answer** \[ \boxed{-\frac{1}{4}\cos(4x)+C} \]

Recognizing \(\frac{1}{x}\)

The function \(\frac{1}{x}\) is a special case because its power is \(n=-1\). The ordinary power rule does not apply when \(n=-1\).

Instead, we use the natural logarithm rule.

Natural Logarithm Rule
\[ \int \frac{1}{x}\,dx = \ln|x|+C \]
Worked Example

Evaluate:

\[ \int \frac{1}{x}\,dx \]
**Step 1: Recognize the function**

The function is the reciprocal of \(x\).

**Step 2: Apply the logarithm rule** \[ \int \frac{1}{x}\,dx = \ln|x|+C \]
**Final Answer** \[ \boxed{\ln|x|+C} \]

Recognizing \(\frac{a}{bx+d}\)

Another important form is a constant divided by a linear expression. When you recognize this form, you can use the logarithm rule.

Constant over Linear Function
\[ \int \frac{a}{bx+d}\,dx = \frac{a}{b}\ln|bx+d|+C \]
Worked Example

Evaluate:

\[ \int \frac{6}{2x+5}\,dx \]
**Step 1: Recognize the function**

The numerator is \(6\), and the denominator is the linear expression \(2x+5\).

**Step 2: Identify the constants** \[ a=6,\qquad b=2 \]
**Step 3: Apply the logarithm rule** \[ \begin{aligned} \int \frac{6}{2x+5}\,dx &= \frac{6}{2}\ln|2x+5|+C\\ &= 3\ln|2x+5|+C \end{aligned} \]
**Final Answer** \[ \boxed{3\ln|2x+5|+C} \]

Recognizing the Correct Rule

Use this table to identify common functions and the integration rule associated with each one.

\(\sin(ax)\) Sine Trigonometric rule
\(\frac{1}{x}\) Reciprocal of \(x\) Natural logarithm rule

Common Mistakes to Avoid

**1. Forgetting the extra factor**

When integrating \(e^{ax}\), \(\sin(ax)\), or \(\cos(ax)\), remember the extra factor \(\frac{1}{a}\).

**2. Using the power rule for \(\frac{1}{x}\)**

Remember that when \(n=-1\), the ordinary power rule cannot be used. Use the logarithm rule instead.

**3. Forgetting the constant of integration**

Always remember to include \(+C\) in your indefinite integration answers.
