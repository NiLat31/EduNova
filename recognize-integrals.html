Recognize Integrals

Learn how to recognize common functions and choose the correct integration formula quickly and confidently.

How to Recognize an Integral

Before integrating, first look carefully at the function. Many integration questions use functions that follow a familiar pattern.

If you recognize the pattern, you can choose the correct formula instead of trying to find a completely new method.

Keep in mind

The most important skill in this lesson is recognizing the form of the function before integrating it.

Start With the Basic Rules

These are some of the most common forms you should recognize immediately.

Power of x

∫ x n dx = x n + 1 n + 1 + C

Constant

∫ a dx = ax + C

Power of a linear function

∫ ( ax + b ) n dx = ( ax + b ) n + 1 a ( n + 1 ) + C

Recognizing e a x

When you see an exponential function containing e a x , use the exponential integration rule.

The rule

∫ e a x dx = 1 a e a x + C

The important part is the number multiplying x in the exponent.

Recognizing Trigonometric Integrals

Trigonometric functions follow a repeating cycle. This makes it easier to remember what happens when differentiating or integrating them.

Teacher's shortcut

Differentiation moves clockwise around the cycle. Integration moves anti-clockwise.

Common Trigonometric Integrals

Once you recognize the function, use the corresponding formula.

Sine

∫ sin ( ax ) dx = − 1 a cos ( ax ) + C

Integration moves anti-clockwise.

Cosine

∫ cos ( ax ) dx = 1 a sin ( ax ) + C

Integration moves anti-clockwise.

Negative sine

∫ − sin ( ax ) dx = 1 a cos ( ax ) + C

Move anti-clockwise from −sin to cos.

Recognizing 1 x

The function 1 x is a special case because the usual power rule does not work when the power is n=−1.

The special rule

∫ 1 x dx = ln | x | + C

So, whenever you see 1 x , think of ln|x|.

Recognizing a bx + d

Another important form is a constant divided by a linear function.

The rule

∫ a bx + d dx = a b ln | bx + d | + C

Notice that the coefficient b appears in the denominator of the answer.

Recognize the Pattern

Use this table to quickly identify the most common forms.

Function you see Think of Integration result
x n Power rule x n + 1 n + 1 + C
e ax Exponential rule 1 a e ax + C
cos ( ax ) Trig cycle 1 a sin ( ax ) + C
sin ( ax ) Trig cycle − 1 a cos ( ax ) + C
1 x Logarithm rule ln | x | + C
a bx + d Logarithm rule a b ln | bx + d | + C

Common Mistakes

Forgetting the coefficient

If the function contains ax, remember the factor 1 a in the answer.

Using the power rule for 1/x

Do not use the ordinary power rule when n=−1. Use the logarithm rule instead.

Forgetting the sign in sine integration

The function is sine, so integration moves anti-clockwise from sin x to − cos x .

Lesson Summary

  • Look at the form of the function before integrating.
  • Use the power rule for powers of x.
  • Recognize e ax as an exponential function.
  • Use the trig cycle for sine and cosine.
  • Differentiation moves clockwise.
  • Integration moves anti-clockwise.
  • Recognize 1 x as a logarithm.
  • For a bx + d , use the logarithm rule with a b in front.
  • Always add the constant of integration C.
