Recognize Integrals

Learn how to recognize familiar functions before choosing the correct integration rule.

Recognize Before You Integrate

Integration becomes much easier when you first recognize the form of the function. Many functions can be integrated using rules that come directly from differentiation.

The main idea is simple: integration reverses differentiation.

Keep in mind

Before integrating, look carefully at the function. Ask yourself: “What function would give me this when I differentiate it?”

1. Important Rules to Remember

These rules are the foundation for many of the integrals you will meet.

Power of x

∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C

where n ≠ −1.

Example

Integrate x⁴

∫ x⁴ dx
= x⁵ / 5 + C

Constant

∫ a dx = ax + C
Example

Integrate 7

∫ 7 dx
= 7x + C

A power of (ax + b)

∫(ax + b)ⁿ dx = (ax + b)ⁿ⁺¹ / [a(n + 1)] + C

where n ≠ −1.

Example

Integrate (2x + 3)⁴

∫(2x + 3)⁴ dx
= (2x + 3)⁵ / [2(5)] + C
= (2x + 3)⁵ / 10 + C

2. Recognizing eᵃˣ

If you see an exponential function of the form eᵃˣ, recognize that its derivative contains an extra factor of a.

∫ eᵃˣ dx = (1/a)eᵃˣ + C

Why do we divide by a?

Because when we differentiate eᵃˣ, the chain rule gives us an extra a.

Therefore, integration must cancel that extra a.

Worked Example

Integrate e³ˣ

∫ e³ˣ dx
= (1/3)e³ˣ + C
Check by differentiating:
d/dx [(1/3)e³ˣ]
= (1/3)(3e³ˣ)
= e³ˣ

3. Recognizing sin(ax) and cos(ax)

Trigonometric functions are closely connected through differentiation.

Your teacher's circle is a useful way to remember the direction of the functions.

The Sin–Cos Cycle

During differentiation, move clockwise. During integration, move anti-clockwise.

Differentiation

Move clockwise:

sin x → cos x → −sin x → −cos x
Integration

Move anti-clockwise:

sin x → −cos x → −sin x → cos x

Integrating cos(ax)

∫ cos(ax) dx = (1/a)sin(ax) + C

The factor 1/a is needed because differentiating sin(ax) produces an extra factor of a.

Worked Example

Integrate cos(4x)

∫ cos(4x) dx
= (1/4)sin(4x) + C
Check:
d/dx [(1/4)sin(4x)]
= (1/4)(4cos(4x))
= cos(4x)

Integrating sin(ax)

∫ sin(ax) dx = −(1/a)cos(ax) + C

Notice the negative sign. When integrating sin, we move anti-clockwise from sin to −cos.

Worked Example

Integrate sin(5x)

∫ sin(5x) dx
= −(1/5)cos(5x) + C
Check:
d/dx [−(1/5)cos(5x)]
= −(1/5)(−5sin(5x))
= sin(5x)

4. Recognizing 1/x

There is one important exception to the power rule.

If you see:

∫ (1/x) dx

you should immediately recognize it as a logarithmic integral.

∫ (1/x) dx = ln|x| + C

Why can't we use the power rule?

Since 1/x = x⁻¹, it may look like we can use the power rule.

But the power rule would require us to divide by n + 1.

Here n = −1, so:

n + 1 = −1 + 1 = 0

Division by zero is not allowed. Therefore, n = −1 is the special case and gives a logarithm instead.

Worked Example

Integrate 1/x

∫ (1/x) dx
= ln|x| + C

5. Recognizing a/(bx + d)

Another important form is:

∫ a/(bx + d) dx

This has the same basic idea as integrating 1/x, but there is an extra linear expression in the denominator.

∫ a/(bx + d) dx = (a/b)ln|bx + d| + C

Why do we divide by b?

Differentiate ln|bx + d| and the chain rule gives an extra factor of b.

Therefore, we divide by b to cancel that extra factor.

Worked Example

Integrate 5/(2x + 3)

∫ 5/(2x + 3) dx
= (5/2)ln|2x + 3| + C
Check by differentiating:
d/dx [(5/2)ln|2x + 3|]
= (5/2) × 2/(2x + 3)
= 5/(2x + 3)

7. Common Recognition Mistakes

Forgetting the coefficient inside the function

For example, ∫ cos(3x) dx is not simply sin(3x). The answer must include the factor 1/3.

Forgetting the negative sign with sin

Remember: ∫ sin(ax) dx = −(1/a)cos(ax) + C.

Using the power rule for 1/x

x⁻¹ is the special case where the power rule does not work. Its integral is ln|x| + C.

Forgetting the derivative of the inside

When the inside is ax + b, the coefficient a must be accounted for in the integral.

Recognize First

The key skill in this topic is recognizing the structure of the function before applying a rule.

eᵃˣ → divide by a
cos(ax) → sin(ax), divide by a
sin(ax) → −cos(ax), divide by a
1/x → ln|x|
