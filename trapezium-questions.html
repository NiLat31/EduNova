Practice Questions

Test your understanding of the Trapezium Rule with exam-style questions and fully worked solutions.

KEEP IN MIND

  • n is the number of intervals.
  • The width of each interval is h = (b − a) / n.
  • The first and last y-values are used once.
  • All interior y-values are multiplied by 2.
  • The Trapezium Rule gives an approximation, so use ≈.

Overestimate: the trapezia lie mostly above the curve, so the estimated area is greater than the true area.

Underestimate: the trapezia lie mostly below the curve, so the estimated area is less than the true area.

Quick check: compare the straight-line approximation with the curve.

Question 1

3 MARKS

The table below gives values of a function at equally spaced values of x.

x 0 1 2 3 4
y 2 3 5 4 7

Use the Trapezium Rule to estimate the area under the curve between x = 0 and x = 4.

Fully Worked Answer
Step 1: Find the number of intervals, n
x = 0, 1, 2, 3, 4

There are 4 intervals.

n = 4
Step 2: Find the width of each interval, h
h = (b − a) / n

h = (4 − 0) / 4

h = 4 / 4

h = 1
Step 3: Write the Trapezium Rule
A ≈ h/2 [y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]
Step 4: Substitute the values
A ≈ 1/2 [2 + 7 + 2(3 + 5 + 4)]
Step 5: Add the interior y-values
3 + 5 + 4 = 12

2(12) = 24
Step 6: Simplify inside the brackets
A ≈ 1/2 [2 + 7 + 24]

A ≈ 1/2 [33]
Step 7: Calculate the final value
A ≈ 33/2

A ≈ 16.5
∴ Estimated area ≈ 16.5 square units

Question 6

3 MARKS

A curve is concave upward throughout an interval.

When the Trapezium Rule is used over this interval, will the estimated area be an overestimate or an underestimate?

Explain your answer.

Fully Worked Answer
Step 1: Identify the shape of the curve
The curve is concave upward.
Step 2: Compare the trapezium with the curve
For a concave upward curve, the straight line joining two points on the curve lies above the curve between those points.
Step 3: Decide whether the area is larger or smaller
Because the trapezia lie above the curve, the trapezium areas are larger than the actual area under the curve.
∴ The Trapezium Rule gives an OVERestimate.

Question 8

5 MARKS

A straight-line Trapezium Rule approximation lies above the curve throughout the interval.

The estimated area is 24.8 square units.

State whether the Trapezium Rule gives an overestimate or an underestimate. State whether the true area is greater than or less than 24.8 square units. Also explain what generally happens to the accuracy when the number of intervals is increased.

Fully Worked Answer
Step 1: Compare the straight lines with the curve
The straight-line approximation lies above the curve throughout the interval.
Step 2: Decide whether the estimated area is larger
Since the trapezia extend above the curve, they include more area than the true area under the curve.
Step 3: Identify the type of error
Estimated area > True area

Therefore, the estimate is an overestimate.
Step 4: Compare the true area with 24.8
Estimated area = 24.8

Estimated area > True area

Therefore:

True area < 24.8
Step 5: Increasing the number of intervals
Increasing the number of intervals makes each trapezium narrower. The straight-line approximation usually follows the curve more closely, so the estimate generally becomes more accurate.
∴ Overestimate.

∴ True area < 24.8 square units.

∴ More intervals generally give a more accurate estimate.
