Question 01

Evaluate

Evaluate the following integral:

∫ 3x + 5 (x + 1)(x + 2) dx
Complete Solution
Step 1: Write the partial fractions

Since the denominator contains two different linear factors, write:

3x + 5 (x + 1)(x + 2) = A x + 1 + B x + 2
Step 2: Multiply by the denominator

Multiply both sides by (x + 1)(x + 2):

3x + 5 = A(x + 2) + B(x + 1)
Step 3: Find A

Put x = −1:

3(−1) + 5 = A(−1 + 2) + B(−1 + 1)
2 = A(1) + B(0)
A = 2
Step 4: Find B

Put x = −2:

3(−2) + 5 = A(−2 + 2) + B(−2 + 1)
−1 = A(0) + B(−1)
B = 1
Step 5: Rewrite the integral
∫ [ 2 x + 1 + 1 x + 2 ] dx
Step 6: Integrate
2ln|x + 1| + ln|x + 2| + C
∫ 3x + 5 (x + 1)(x + 2) dx = 2ln|x + 1| + ln|x + 2| + C
Question 02

Find the Answer

Find the following indefinite integral:

∫ 1 (x − 1)(x + 2) dx
Complete Solution
Step 1: Write the partial fractions
1 (x − 1)(x + 2) = A x − 1 + B x + 2
Step 2: Multiply by the denominator
1 = A(x + 2) + B(x − 1)
Step 3: Find A

Put x = 1:

1 = A(3) + B(0)
A = 1 3
Step 4: Find B

Put x = −2:

1 = A(0) + B(−3)
B = − 1 3
Step 5: Rewrite the integral
∫ [ 1 3(x − 1) − 1 3(x + 2) ] dx
Step 6: Integrate
1 3 ln|x − 1| − 1 3 ln|x + 2| + C
Answer: 1 3 ln|x − 1| − 1 3 ln|x + 2| + C
Question 03

Evaluate

Evaluate the following integral:

∫ 1 (x + 1)(x − 2)2 dx
Complete Solution
Step 1: Write the partial fractions

Because (x − 2) is repeated, include both powers of the repeated factor:

1 (x + 1)(x − 2)2 = A x + 1 + B x − 2 + C (x − 2)2
Step 2: Multiply by the denominator
1 = A(x − 2)2 + B(x + 1)(x − 2) + C(x + 1)
Step 3: Find A

Put x = −1:

1 = A(−3)2 + B(0)(−3) + C(0)
1 = 9A
A = 1 9
Step 4: Find C

Put x = 2:

1 = A(0)2 + B(3)(0) + C(3)
1 = 3C
C = 1 3
Step 5: Find B

Put x = 0:

1 = A(−2)2 + B(1)(−2) + C(1)
1 = 4A − 2B + C

Substitute A = 1 9 and C = 1 3 :

1 = 4 9 − 2B + 1 3
1 = 7 9 − 2B
2 9 = −2B
B = − 1 9
Step 6: Rewrite the integral
∫ [ 1 9(x + 1) − 1 9(x − 2) + 1 3(x − 2)2 ] dx
Step 7: Integrate each term
1 9 ln|x + 1| − 1 9 ln|x − 2| + 1 3 ∫(x − 2)−2 dx
∫(x − 2)−2 dx = −(x − 2)−1
= − 1 x − 2
Step 8: Final answer
1 9 ln|x + 1| − 1 9 ln|x − 2| − 1 3(x − 2) + C
Question 04

Evaluate

Evaluate the following integral:

∫ 2x + 3 (x + 1)(x2 + 1) dx
Complete Solution
Step 1: Write the partial fractions

The denominator contains one linear factor and one irreducible quadratic factor.

2x + 3 (x + 1)(x2 + 1) = A x + 1 + Bx + C x2 + 1
Step 2: Multiply by the denominator
2x + 3 = A(x2 + 1) + (Bx + C)(x + 1)
Step 3: Find A

Put x = −1:

−2 + 3 = A(2) + 0
1 = 2A
A = 1 2
Step 4: Compare coefficients

Expand the right-hand side:

A x2 + A + Bx2 + Bx + Cx + C

Group like terms:

(A + B)x2 + (B + C)x + (A + C)

Compare this with:

0x2 + 2x + 3

Therefore:

A + B = 0
B + C = 2
A + C = 3
Step 5: Find B and C

Since A = 1 2 , from A + B = 0:

1 2 + B = 0
B = − 1 2

From A + C = 3:

1 2 + C = 3
C = 5 2
Step 6: Rewrite the integral
∫ [ 1 2(x + 1) + −x + 5 2(x2 + 1) ] dx
Step 7: Separate the integral
1 2 ∫ 1 x + 1 dx + 1 2 ∫ −x + 5 x2 + 1 dx
Step 8: Integrate

For the second integral, split the numerator:

−x + 5 = −x + 5
∫ −x x2 + 1 dx + ∫ 5 x2 + 1 dx

Since the derivative of x2 + 1 is 2x:

∫ −x x2 + 1 dx = − 1 2 ln(x2 + 1)

Also:

∫ 5 x2 + 1 dx = 5tan−1x
Step 9: Final answer
1 2 ln|x + 1| − 1 4 ln(x2 + 1) + 5 2 tan−1x + C
Question 05

Simplify and Integrate

Evaluate the following integral:

∫ x2 + 3 x2 + 1 dx
Complete Solution
Step 1: Compare the numerator and denominator

The numerator and denominator have the same degree, so simplify the fraction first.

x2 + 3 = (x2 + 1) + 2
Step 2: Rewrite the fraction
x2 + 3 x2 + 1 = x2 + 1 x2 + 1 + 2 x2 + 1
Step 3: Simplify
x2 + 3 x2 + 1 = 1 + 2 x2 + 1
Step 4: Integrate
∫ [ 1 + 2 x2 + 1 ] dx
x + 2tan−1x + C
Step 5: Final answer
x + 2tan−1x + C
Question 06

Three Different Forms

Evaluate each of the following integrals.

(a)
∫ 2x x2 + 5 dx
(b)
∫ 1 x2 + 5 dx
(c)
∫ 1 (x + 1)(x + 2) dx
Complete Solution
Part (a)

Consider:

∫ 2x x2 + 5 dx

The derivative of x2 + 5 is 2x.

∫ 2x x2 + 5 dx = ln(x2 + 5) + C
Answer: ln(x2 + 5) + C
Part (b)

Use the standard form:

∫ 1 x2 + a2 dx = 1 a tan−1 x a + C

Here:

a2 = 5
a = √5

Therefore:

∫ 1 x2 + 5 dx = 1 √5 tan−1 x √5 + C
Answer: 1 √5 tan−1 x √5 + C
Part (c)

Write the partial fractions:

1 (x + 1)(x + 2) = A x + 1 + B x + 2

Multiply by (x + 1)(x + 2):

1 = A(x + 2) + B(x + 1)

Put x = −1:

1 = A(1)
A = 1

Put x = −2:

1 = B(−1)
B = −1

Therefore:

1 (x + 1)(x + 2) = 1 x + 1 − 1 x + 2

Integrate:

ln|x + 1| − ln|x + 2| + C
Answer: ln|x + 1| − ln|x + 2| + C

Important distinction

These three integrals have different structures, so they require different approaches.

Derivative over function → logarithmic form.

x2 + a2 in the denominator → inverse tangent form.

Factorised denominator → partial fractions.

Question 07

Evaluate

Evaluate the following integral:

∫ 2x2 + 2x + 2 (x + 1)(x2 + 1) dx
Complete Solution
Step 1: Write the partial fractions
2x2 + 2x + 2 (x + 1)(x2 + 1) = A x + 1 + Bx + C x2 + 1
Step 2: Multiply by the denominator
2x2 + 2x + 2 = A(x2 + 1) + (Bx + C)(x + 1)
Step 3: Find A

Put x = −1:

2 − 2 + 2 = A(2)
2 = 2A
A = 1
Step 4: Find B and C

Expand:

A x2 + A + Bx2 + Bx + Cx + C

Group like terms:

(A + B)x2 + (B + C)x + (A + C)

Compare coefficients with:

2x2 + 2x + 2

Therefore:

A + B = 2
B + C = 2
A + C = 2

Since A = 1:

1 + B = 2
B = 1
1 + C = 2
C = 1
Step 5: Rewrite the integral
∫ [ 1 x + 1 + x + 1 x2 + 1 ] dx
Step 6: Split the second integral
∫ x + 1 x2 + 1 dx
= 1 2 ln(x2 + 1) + tan−1x
Step 7: Final answer
ln|x + 1| + 1 2 ln(x2 + 1) + tan−1x + C
Question 08

Evaluate

Evaluate the following integral:

∫ 5x + 1 (x − 1)(x + 2) dx
Complete Solution
Step 1: Write the partial fractions
5x + 1 (x − 1)(x + 2) = A x − 1 + B x + 2
Step 2: Multiply by the denominator
5x + 1 = A(x + 2) + B(x − 1)
Step 3: Find A

Put x = 1:

5(1) + 1 = A(3)
6 = 3A
A = 2
Step 4: Find B

Put x = −2:

5(−2) + 1 = B(−3)
−9 = −3B
B = 3
Step 5: Rewrite the integral
∫ [ 2 x − 1 + 3 x + 2 ] dx
Step 6: Integrate
2ln|x − 1| + 3ln|x + 2| + C
Step 7: Final answer
2ln|x − 1| + 3ln|x + 2| + C
