Partial Fractions

Practice questions designed to test decomposition, recognition, and careful integration.

QUESTION 01

Partial Fractions

Evaluate:

∫ 3x + 5 (x + 1)(x + 2) dx
STEP-BY-STEP SOLUTION
STEP 01

Since the denominator is a product of two different linear factors, write the fraction in partial fractions:

3x + 5 (x + 1)(x + 2) = A x + 1 + B x + 2
STEP 02

Multiply both sides by (x + 1)(x + 2) to remove the denominators:

3x + 5 = A(x + 2) + B(x + 1)
STEP 03

Let x = -1:

3(-1) + 5 = A(-1 + 2) + B(-1 + 1)
2 = A(1) + B(0)
A = 2
STEP 04

Let x = -2:

3(-2) + 5 = A(-2 + 2) + B(-2 + 1)
-1 = A(0) + B(-1)
B = 1
STEP 05

Substitute the values of A and B:

3x + 5 (x + 1)(x + 2) = 2 x + 1 + 1 x + 2
STEP 06

Integrate each term:

∫ 2 x + 1 dx + ∫ 1 x + 2 dx
= 2ln|x + 1| + ln|x + 2| + C
Answer: 2ln|x + 1| + ln|x + 2| + C
QUESTION 02

Partial Fractions

Find the value of:

∫ 1 (x - 1)(x + 2) dx
STEP-BY-STEP SOLUTION
STEP 01

Write the fraction in partial fractions:

1 (x - 1)(x + 2) = A x - 1 + B x + 2
STEP 02

Multiply through by (x - 1)(x + 2):

1 = A(x + 2) + B(x - 1)
STEP 03

Let x = 1:

1 = A(1 + 2) + B(1 - 1)
1 = 3A
A = 1 3
STEP 04

Let x = -2:

1 = A(-2 + 2) + B(-2 - 1)
1 = -3B
B = - 1 3
STEP 05

Therefore:

1 (x - 1)(x + 2) = 1 3(x - 1) - 1 3(x + 2)
STEP 06

Integrate both terms:

∫ 1 3(x - 1) dx - ∫ 1 3(x + 2) dx
= 1 3 ln|x - 1| - 1 3 ln|x + 2| + C
Answer: 1 3 ln|x - 1| - 1 3 ln|x + 2| + C
QUESTION 03

Repeated Factors

Evaluate:

∫ 1 (x + 1)(x - 2)2 dx
STEP-BY-STEP SOLUTION
STEP 01

Because (x - 2) is repeated, write a separate term for each power:

1 (x + 1)(x - 2)2 = A x + 1 + B x - 2 + C (x - 2)2
STEP 02

Multiply everything by (x + 1)(x - 2)2:

1 = A(x - 2)2 + B(x + 1)(x - 2) + C(x + 1)
STEP 03

Let x = -1:

1 = A(-3)2 + B(0)(-3) + C(0)
1 = 9A
A = 1 9
STEP 04

Let x = 2:

1 = A(0)2 + B(3)(0) + C(3)
1 = 3C
C = 1 3
STEP 05

To find B, compare the coefficient of x2.

0 = A + B

Since A = 1/9:

0 = 1 9 + B
B = - 1 9
STEP 06

Therefore:

1 (x + 1)(x - 2)2 = 1 9(x + 1) - 1 9(x - 2) + 1 3(x - 2)2
STEP 07

Integrate each term separately:

1 9 ln|x + 1| - 1 9 ln|x - 2| + 1 3 ∫(x - 2)-2 dx
STEP 08

For the final term:

∫(x - 2)-2 dx = - (x - 2)-1
= - 1 x - 2

Therefore:

- 1 3 · 1 x - 2 = - 1 3(x - 2)
Answer: 1 9 ln|x + 1| - 1 9 ln|x - 2| - 1 3(x - 2) + C
QUESTION 04

Linear and Quadratic Factors

Find the answer:

∫ 2x + 3 (x + 1)(x2 + 1) dx
STEP-BY-STEP SOLUTION
STEP 01

The denominator contains one linear factor and one quadratic factor. Write:

2x + 3 (x + 1)(x2 + 1) = A x + 1 + Bx + C x2 + 1
STEP 02

Multiply through by (x + 1)(x2 + 1):

2x + 3 = A(x2 + 1) + (Bx + C)(x + 1)
STEP 03

Let x = -1:

2(-1) + 3 = A((-1)2 + 1) + (B(-1) + C)(0)
1 = 2A
A = 1 2
STEP 04

Expand the right-hand side:

A(x2 + 1) + (Bx + C)(x + 1)
= Ax2 + A + Bx2 + Bx + Cx + C
= (A + B)x2 + (B + C)x + (A + C)
STEP 05

Compare coefficients with:

2x + 3 = 0x2 + 2x + 3

Therefore:

A + B = 0
B + C = 2
A + C = 3
STEP 06

Since A = 1/2:

1 2 + B = 0
B = - 1 2

Then:

- 1 2 + C = 2
C = 5 2
STEP 07

Substitute the values:

2x + 3 (x + 1)(x2 + 1) = 1 2(x + 1) + -x + 5 2(x2 + 1)
STEP 08

Split the second fraction into two integrals:

∫ -x 2(x2 + 1) dx + ∫ 5 2(x2 + 1) dx
STEP 09

Integrate:

1 2 ln|x + 1| - 1 4 ln(x2 + 1) + 5 2 tan-1x + C
Answer: 1 2 ln|x + 1| - 1 4 ln(x2 + 1) + 5 2 tan-1x + C
QUESTION 05

Careful Recognition

Evaluate:

∫ x2 + 3 x2 + 1 dx
STEP-BY-STEP SOLUTION
STEP 01

Compare the numerator and denominator:

x2 + 3
x2 + 1

The numerator and denominator have the same degree. We therefore simplify the fraction first.

STEP 02

Rewrite the numerator:

x2 + 3 = (x2 + 1) + 2
STEP 03

Substitute this into the integral:

∫ (x2 + 1) + 2 x2 + 1 dx
STEP 04

Split the fraction:

∫ [ 1 + 2 x2 + 1 ] dx
STEP 05

Integrate each term:

∫1 dx + 2∫ 1 x2 + 1 dx
x + 2tan-1x + C
Answer: x + 2tan-1x + C
QUESTION 06

Three Cases

Evaluate each of the following integrals.

(a)
∫ 2x x2 + 5 dx
SOLUTION (a)
STEP 01

Let:

f(x) = x2 + 5
STEP 02

Differentiate:

f′(x) = 2x
STEP 03

Therefore:

∫ 2x x2 + 5 dx = ln|x2 + 5| + C
Answer: ln(x2 + 5) + C
(b)
∫ 1 x2 + 5 dx
SOLUTION (b)
STEP 01

Rewrite the denominator:

x2 + 5 = x2 + (√5)2
STEP 02

Use the standard integral:

∫ 1 x2 + a2 dx = 1 a tan-1 x a + C
STEP 03

Here, a = √5.

∫ 1 x2 + 5 dx = 1 √5 tan-1 x √5 + C
Answer: 1 √5 tan-1 x √5 + C
(c)
∫ 1 (x + 1)(x + 2) dx
SOLUTION (c)
STEP 01

Write the fraction in partial fractions:

1 (x + 1)(x + 2) = A x + 1 + B x + 2
STEP 02

Multiply through by (x + 1)(x + 2):

1 = A(x + 2) + B(x + 1)
STEP 03

Let x = -1:

1 = A(1) + B(0)
A = 1
STEP 04

Let x = -2:

1 = A(0) + B(-1)
B = -1
STEP 05

Therefore:

1 (x + 1)(x + 2) = 1 x + 1 - 1 x + 2
STEP 06

Integrate:

ln|x + 1| - ln|x + 2| + C
Answer: ln|x + 1| - ln|x + 2| + C
QUESTION 07

Quadratic Factors

Evaluate:

∫ 2x2 + 2x + 2 (x + 1)(x2 + 1) dx
STEP-BY-STEP SOLUTION
STEP 01

Write the partial fraction form:

2x2 + 2x + 2 (x + 1)(x2 + 1) = A x + 1 + Bx + C x2 + 1
STEP 02

Multiply through:

2x2 + 2x + 2 = A(x2 + 1) + (Bx + C)(x + 1)
STEP 03

Let x = -1:

2 - 2 + 2 = A(2)
2 = 2A
A = 1
STEP 04

Expand:

A(x2 + 1) + (Bx + C)(x + 1)
= (A + B)x2 + (B + C)x + (A + C)
STEP 05

Compare coefficients:

A + B = 2
B + C = 2
A + C = 2

Since A = 1:

1 + B = 2
B = 1
1 + C = 2
C = 1
STEP 06

Therefore:

2x2 + 2x + 2 (x + 1)(x2 + 1) = 1 x + 1 + x + 1 x2 + 1
STEP 07

Split the second fraction:

∫ 1 x + 1 dx + ∫ x x2 + 1 dx + ∫ 1 x2 + 1 dx
STEP 08

Integrate each part:

ln|x + 1| + 1 2 ln(x2 + 1) + tan-1x + C
Answer: ln|x + 1| + 1 2 ln(x2 + 1) + tan-1x + C
QUESTION 08

Final Challenge

Evaluate:

∫ 5x + 1 (x - 1)(x + 2) dx
STEP-BY-STEP SOLUTION
STEP 01

Write the partial fraction form:

5x + 1 (x - 1)(x + 2) = A x - 1 + B x + 2
STEP 02

Multiply through:

5x + 1 = A(x + 2) + B(x - 1)
STEP 03

Let x = 1:

5(1) + 1 = A(1 + 2) + B(1 - 1)
6 = 3A
A = 2
STEP 04

Let x = -2:

5(-2) + 1 = A(-2 + 2) + B(-2 - 1)
-9 = -3B
B = 3
STEP 05

Substitute the values:

5x + 1 (x - 1)(x + 2) = 2 x - 1 + 3 x + 2
STEP 06

Integrate:

2ln|x - 1| + 3ln|x + 2| + C
Answer: 2ln|x - 1| + 3ln|x + 2| + C
