VECTORS • TOPIC 01 / 04

Definition of Vectors.

Learn what vectors are, how they are represented, how they can be added, and how equal, opposite and parallel vectors are identified.

A vector tells us two things.

It tells us how much and which way. This combination of magnitude and direction is what makes a vector different from an ordinary number.

PART 01 • THE BASICS

What is a vector?

A vector is a quantity that has both magnitude and direction. We often represent a vector geometrically using a directed line segment. The arrow shows its direction, while the length of the line represents its magnitude.

01 • MAGNITUDE

How much?

The magnitude describes the size or length of the vector.

02 • DIRECTION

Which way?

The direction describes the orientation in which the vector acts.

Vector = Magnitude + Direction
Both properties are needed to completely describe a vector.
KEY IDEA

The arrowhead is important. It tells us which end of the vector is the terminal end and therefore shows the direction of the vector.

Reading a vector diagram

VECTOR REPRESENTATION
The vector begins at A and ends at B. The arrowhead is placed at B, so the direction is from A towards B. The length of the directed line represents its magnitude.

How are vectors written?

Vectors can be represented using a bold lowercase letter, such as a, or using an arrow above a letter. A vector can also be named using two points, where the order tells us the direction.

a or AB
The second notation means the vector from A to B.
ORDER MATTERS

The vector from A to B has the opposite direction to the vector from B to A.

PART 02 • VECTOR ADDITION

Adding vectors.

Vectors can be added to produce a new vector called the resultant. Geometrically, we can add vectors by placing the tail of the second vector at the head of the first vector.

a + b = resultant
The resultant joins the starting point to the final point.

Head-to-tail addition

ANIMATED RESULTANT
First move b so that its tail begins at the head of a. Here the vectors are perpendicular, making the resultant easy to see. The resultant runs directly from the original starting point to the final endpoint.

Component addition

Vectors can also be added using their components. Add the horizontal components together and add the vertical components together.

a = (a₁, a₂) + b = (b₁, b₂)
a + b = (a₁ + b₁, a₂ + b₂)
Add corresponding components.
WORKED EXAMPLE

Add two vectors

Let a = (3, 2) and b = (4, 1).

1

Add the first components: 3 + 4 = 7.

2

Add the second components: 2 + 1 = 3.

3

Therefore, a + b = (7, 3).

PART 03 • VECTOR RELATIONSHIPS

Equal, opposite and parallel.

Vectors can have important relationships with one another. The position of a vector does not change its identity as a vector. What matters here is its magnitude and direction.

Equal vectors

Equal vectors have the same magnitude and the same direction. They do not have to start at the same point.

Opposite vectors

Opposite vectors have the same magnitude but point in opposite directions. If one vector is a, its opposite can be written as −a.

Parallel vectors

Parallel vectors have directions that lie along parallel lines. They may point in the same direction or in opposite directions.

REMEMBER

Equal vectors must have the same magnitude and direction. Opposite vectors have the same magnitude but opposite directions. Parallel vectors have directions along parallel lines.

CHECK YOUR UNDERSTANDING

Common mistakes.

Forgetting direction

Two vectors can have the same length but still be different if they point in different directions.

Reversing the order

The vector from A to B is not the same as the vector from B to A. Reversing the direction changes the vector.

Joining the wrong endpoints

For head-to-tail addition, the tail of the second vector must begin at the head of the first.

Confusing parallel with equal

Parallel vectors describe their direction relationship. Equal vectors must also have the same magnitude.

TOPIC 01 • SUMMARY

The four ideas to remember.

  • A vector has both magnitude and direction.
  • A directed line segment can represent a vector.
  • Vectors can be added using the head-to-tail method.
  • Equal, opposite and parallel vectors describe different relationships between vectors.
