Topic 01

Understanding vectors from the ground up.

A vector describes a movement with both a size and a direction. Once those two ideas are clear, vector notation, addition, components, and relationships between vectors become much easier to understand.

01

What is a vector?

A vector has both magnitude and direction.

Magnitude

How much?

The magnitude tells us the size or length of a vector. It answers the question: how far has the movement been?

Direction

Which way?

The direction tells us where the vector points. It answers the question: in which direction does the movement take place?

Vector = Magnitude + Direction
Both pieces of information are needed to completely describe a vector.
Key idea

A scalar has magnitude only, while a vector has both magnitude and direction.

The arrow points from A to B, showing the vector's direction.

How are vectors written?

A vector from point A to point B is written as AB. The arrow above the letters shows the direction from the first point to the second.

Direction matters

AB points from A to B. Reversing the order changes the direction.

Same length, different direction

Two vectors can have the same magnitude while pointing in different directions.

Equal vectors

Equal vectors have the same magnitude and the same direction, even if they are located in different places.

Why does the order matter?

02

Adding vectors.

Vectors can be combined to create a resultant vector.

When vectors are added, we combine their movements. A useful way to visualise this is the head-to-tail method.

a + b = resultant
The resultant connects the starting point to the final point.

Head-to-tail addition

Move the second vector so that its tail starts at the head of the first vector.

AB + BC = AC
The second vector starts where the first vector ends.
The resultant vector AC connects the starting point A directly to the final point C.
03

Adding vectors using components.

Break each vector into horizontal and vertical parts.

A vector does not have to be treated as one complicated diagonal movement. We can split it into two simpler movements: one horizontal and one vertical.

Horizontal component

Left and right

The horizontal component describes how far the vector moves along the horizontal direction.

horizontal
Vertical component

Up and down

The vertical component describes how far the vector moves along the vertical direction.

vertical
Think of it this way

A diagonal vector can be understood as a combination of a horizontal movement and a vertical movement.

Now use the vectors we already know.

From the previous section, we added the vectors from A to B and from B to C. These are written as AB and BC. Each can also be described using horizontal and vertical components.

AB + BC = AC

Writing the components

We can give each vector two components: one horizontal component and one vertical component. Suppose AB has components (x₁,y₁) and BC has components (x₂,y₂).

AB = (x₁,y₁)+BC = (x₂,y₂)
AC = (x₁ + x₂, y₁ + y₂)
Worked example

Add the components.

1

Let \\(\mathbf a=(3,2)\\) and \\(\mathbf b=(4,-1)\\).

2

Add the horizontal components: \\(3+4=7\\).

3

Add the vertical components: \\(2+(-1)=1\\).

4

Therefore, \\(\mathbf a+\mathbf b=(7,1)\\).

Component rule

Add the horizontal components together and the vertical components together.

04

Equal and opposite vectors.

Vectors can be compared by looking at their magnitude and direction.

Two vectors may have the same magnitude and direction, making them equal, or the same magnitude but opposite directions, making them opposite vectors.

Equal vectors

Two vectors are equal when they have the same magnitude and the same direction.

\\[\mathbf a=\mathbf b\\]

Opposite vectors

Two vectors are opposite when they have the same magnitude but opposite directions.

\\[\mathbf b=-\mathbf a\\]

A vector and its negative.

If \\(\mathbf a\\) points in one direction, then \\(-\mathbf a\\) has exactly the same magnitude but points in the opposite direction.

\\[|\mathbf a|=|-\mathbf a|\\]

\\[\mathbf a+(-\mathbf a)=\mathbf0\\]
05

Parallel vectors.

Vectors can point in the same or opposite directions.

These vectors are parallel because they have the same direction. Parallel vectors may have different magnitudes.

Same direction vs opposite direction

If two parallel vectors point in the same direction, their scalar multiple is positive. If one points exactly opposite to the other, the scalar multiple is negative. The magnitude tells us how long each vector is.

Algebraic test

How do we know algebraically that two vectors are parallel?

Two vectors are parallel if one can be written as a scalar multiple of the other. In other words, there must be a number k such that \\(\mathbf v=k\mathbf u\\). The number \\(k\\) is called a scalar.

\\[\boxed{\mathbf v=k\mathbf u}\\]
k > 0same direction
k < 0opposite direction
Worked example

Are \\(\mathbf u=(2,3)\\) and \\(\mathbf v=(6,9)\\) parallel?

Compare the corresponding components:

1
Find the scale factor.

\\[\frac{6}{2}=3\\]

2
Check the second component.

\\[\frac{9}{3}=3\\]

3
Write the vector relationship.

\\[\mathbf v=(6,9)=3(2,3)=3\mathbf u\\]

Conclusion

Since \\(\mathbf v=3\mathbf u\\), one vector is a scalar multiple of the other. Therefore, the vectors are parallel. Because \\(3>0\\), they point in the same direction.

Keep in mind

Two vectors are parallel when one is a scalar multiple of the other.

The algebraic test is \\(\mathbf v=k\mathbf u\\).

A positive scalar gives the same direction, while a negative scalar gives the opposite direction.

The same value of \\(k\\) must work for every corresponding component.
