Definition of Vectors.

Understand what vectors are, how direction and magnitude work, how vectors can be added and compared, and how the same vector can be written geometrically or algebraically.

Start here

A vector tells you how far, and in which direction.

A vector is more than a number. It describes a movement with both magnitude and direction. In this lesson, we will build that idea from diagrams all the way to algebraic notation.

01

What is a vector?

The two ingredients that completely describe a vector.

A vector has magnitude and direction.

The magnitude tells us the size or length of the vector. The direction tells us where the vector points. We usually represent a vector with a directed line segment, so the arrowhead shows its direction.

Magnitude How long the vector is.
Direction Which way the vector points.
Vector Magnitude + direction together.
Keep in mind

A scalar has magnitude only. A vector has both magnitude and direction.

Equal vectors

Two vectors are equal when they have the same magnitude and the same direction. They do not need to start at the same point.

Adding vectors.

Use the head-to-tail method to build a resultant.

Head-to-tail addition

To add two vectors, place the tail of the second vector at the head of the first. The resultant vector joins the original starting point to the final endpoint.

The resultant is the vector from start to finish.

Key idea

Vector addition is about combining movements. The resultant gives the single movement that has the same overall effect.

03

Adding vectors using components.

Break a vector into simpler horizontal and vertical movements.

Horizontal component

Left and right

The horizontal component tells us how far the vector moves along the horizontal axis.

x-component → left / right
Vertical component

Up and down

The vertical component tells us how far the vector moves along the vertical axis.

y-component → up / down

Component addition

If a = (x₁, y₁) and b = (x₂, y₂), add corresponding components.

a + b = (x₁ + x₂, y₁ + y₂)
Worked example

Add the components.

Suppose a = (3, 2) and b = (4, −1).

1

Add the horizontal components: 3 + 4 = 7.

2

Add the vertical components: 2 + (−1) = 1.

3

Therefore, a + b = (7, 1).

05

Parallel vectors.

Use an algebraic multiplier to describe vectors pointing along the same line.

What does parallel mean?

Two vectors are parallel when they have the same or opposite direction. Their lengths can be different. Algebraically, one vector must be a scalar multiple of the other.

b = λa

General algebraic test for parallel vectors.

λ > 0

Same direction.

λ < 0

Opposite direction.

Example: If a = (2, 3, 1) and b = (6, 9, 3), then b = 3a. Therefore, the vectors are parallel and point in the same direction.
Component check

For a = (x₁,y₁,z₁) and b = (x₂,y₂,z₂), the vectors are parallel when their components have one common multiplier: (x₂,y₂,z₂) = λ(x₁,y₁,z₁).

Vectors algebraically.

A vector can be written as a column vector or using i, j and k.

Two ways to write the same vector

In three dimensions, a vector can be written as a column of its components, or as a combination of the unit vectors i, j and k.
