Integration • Topic 06

Integration using
Partial Fractions

Learn how to recognize when an algebraic fraction should be integrated directly, when a standard result applies, and when partial fractions can break a complicated fraction into simpler parts.

A/(x+a) + B/(x+b)
01 • The idea

Look at the fraction first

Some integrals contain algebraic fractions. Before choosing a method, look carefully at the numerator and denominator. A fraction may look familiar, but a small change can lead to a completely different integration method.

The key question

Do not automatically use partial fractions just because you see a fraction. First ask: “What does the structure of this fraction tell me?”

02 • Three similar integrals

Small changes can change the method

These three integrals look very similar. However, each one gives us a different clue about how it should be integrated. This is why recognition is so important.

01 • DERIVATIVE

Numerator matches the derivative

∫ x x² + 1 dx

The derivative of the denominator is 2x, so the numerator is a constant multiple of it.

Logarithmic rule
02 • SPECIAL FORM

Denominator is x² + a²

∫ 1 x² + 1 dx

The numerator is not related to the derivative, but the denominator has the special form x² + a².

Arctangent rule
03 • FACTORISE

Denominator can be factorised

∫ 1 x² − 1 dx

The denominator is a difference of squares: (x − 1)(x + 1).

Partial fractions

One glance. Three different methods.

The important skill is to recognize the structure before doing the calculation.

Derivative of denominator → logarithmic rule

x² + a² → arctangent rule

Factorisable denominator → partial fractions

03 • Worked Example 1

Recognize the logarithmic form

∫ x x² + 1 dx

The denominator is:

f(x) = x² + 1

Its derivative is:

f′(x) = 2x

The numerator is x, which is half of 2x.

x = 1 2 (2x)

Therefore:

∫ x x² + 1 dx = 1 2 ln(x² + 1) + C
04 • Worked Example 2

Recognize the arctangent form

∫ 1 x² + 1 dx

The denominator is still x² + 1, but the numerator has changed.

The derivative of the denominator is:

2x

Our numerator is only 1, so the logarithmic rule does not apply.

Instead, recognize the standard form:

∫ 1 x² + a² dx = 1 a tan⁻¹ x a + C

Here, a = 1.

tan⁻¹x + C
05 • Worked Example 3

Recognize when to factorise

∫ 1 x² − 1 dx

This looks similar to the previous example, but the minus sign changes the structure.

Factorise the denominator:

x² − 1 = (x − 1)(x + 1)

Now the fraction can be written as:

1 (x − 1)(x + 1) = A x − 1 + B x + 1

Multiplying through by (x − 1)(x + 1) gives:

1 = A(x + 1) + B(x − 1)

Setting x = 1 gives:

A = 1/2

Setting x = −1 gives:

B = −1/2

Therefore:

1 x² − 1 = 1 2(x − 1) − 1 2(x + 1)

Integrating each part:

1 2 ln|x − 1| − 1 2 ln|x + 1| + C

These logarithms can also be combined:

1 2 ln |x − 1| |x + 1| + C
06 • Important distinction

Know which method belongs to which fraction

The three examples above are deliberately similar. Their purpose is to train you to recognize the method before you begin calculating.

Derivative pattern

If the numerator is the derivative of the denominator, or a constant multiple of it, use the logarithmic rule.

Positive quadratic

If the denominator is in the form x² + a² and the numerator does not match its derivative, use the arctangent rule.

Factorisable denominator

If the denominator can be split into suitable factors, partial fractions may be the method you need.

Do not force a method

A fraction can look familiar without belonging to the same integration pattern.

Look → Differentiate or factorise → Recognize → Integrate.

07 • Partial Fractions with Linear Factors

Splitting a fraction into simpler parts

When the denominator is made from different linear factors, we can split the fraction into simpler fractions.

The basic form

P(x) (x + a)(x + b) = A x + a + B x + b

Each different linear factor gets its own constant numerator.

Let's use a simple example.

∫ 3x + 5 (x + 1)(x + 2) dx

Start by writing:

3x + 5 (x + 1)(x + 2) = A x + 1 + B x + 2

Multiply through by (x + 1)(x + 2):

3x + 5 = A(x + 2) + B(x + 1)

Put x = −1:

2 = A

Put x = −2:

−1 = B

Therefore:

3x + 5 (x + 1)(x + 2) = 2 x + 1 − 1 x + 2

Now integrate:

2ln|x + 1| − ln|x + 2| + C
08 • Partial Fractions with a Quadratic Factor

When the denominator contains a quadratic

A quadratic factor is treated differently from a linear factor. The numerator above a quadratic factor must be linear.

Remember this structure

For a linear factor:

A x + a

For a quadratic factor:

Bx + C x² + a²

Consider:

∫ 2x² + 2x + 2 (x + 1)(x² + 1) dx

The denominator contains one linear factor, x + 1, and one quadratic factor, x² + 1.

So the correct partial-fraction form is:

2x² + 2x + 2 (x + 1)(x² + 1) = A x + 1 + Bx + C x² + 1

In this example, the decomposition is:

2x² + 2x + 2 (x + 1)(x² + 1) = 1 x + 1 + x + 1 x² + 1

Now split the integral:

∫ 1 x + 1 dx + ∫ x + 1 x² + 1 dx

Split the second numerator so that each part can be recognized:

x + 1 x² + 1 = x x² + 1 + 1 x² + 1

Now the first part uses the logarithmic rule, while the second part uses the arctangent rule.

ln|x + 1| + 1 2 ln(x² + 1) + tan⁻¹x + C

One fraction can contain more than one idea

Partial fractions does not always finish the problem. After splitting the fraction, look at each new fraction again. One part may use the logarithmic rule while another part may use the arctangent rule.

09 • The process

A reliable method

1 Look at the denominator

Decide whether the fraction already matches a known integration pattern.

2 Factorise if needed

Factorise the denominator as far as possible.

3 Write the partial fractions

Give each factor the correct numerator.

4 Find the unknown constants

Substitute useful values of x or compare coefficients.

5 Integrate the simpler fractions

Look again at each fraction and choose the appropriate integration rule.

The habit to remember

Factorise → Decompose → Recognize → Integrate

10 • Common mistakes

Watch out for these

  • Using partial fractions immediately. First check whether the fraction already matches the logarithmic or arctangent form.
  • Missing the sign in x² ± a². x² + a² and x² − a² lead to different methods.
  • Giving a quadratic factor the wrong numerator. A quadratic factor needs a linear numerator such as Bx + C.
  • Forgetting to factorise completely. Partial fractions depends on the factorised form of the denominator.
  • Integrating before simplifying the fraction. Complete the decomposition first, then integrate.
  • Forgetting +C. These are indefinite integrals, so the constant of integration is still required.

Quick Summary

  1. Look at the numerator and denominator before choosing a method.
  2. If the numerator is related to the derivative of the denominator, consider the logarithmic rule.
  3. If the denominator is x² + a², consider the arctangent rule.
  4. If the denominator can be factorised into suitable factors, use partial fractions.
  5. A linear factor receives a constant numerator.
  6. A quadratic factor receives a linear numerator.
  7. After decomposing, look at each fraction again and choose the correct integration rule.
A x + a + Bx + C x² + a²
