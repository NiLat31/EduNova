Integration • Topic 04

Practice Questions

Test your understanding of integrating functions in the form x² + a². Read carefully. Some of these questions are designed to catch a careless step.

Ready for the challenge?

Start with the direct questions, then work your way through the traps. Do not rush to the formula. First look carefully at the denominator and decide whether the expression is already in the required form or needs to be rearranged.

Challenge rule: Try each question before opening the answer. Several questions are deliberately written so that a quick application of the formula can lead to the wrong answer.

Question 01 • Direct

Evaluate the following integral.

∫ 1 x² + 16 dx
Complete Solution
Step 1: Compare with the standard form

The standard form is:

∫ 1 x² + a² dx = 1 a tan⁻¹ ( x a ) + C
Step 2: Identify a²

Comparing the denominator with x² + a²:

a² = 16
Step 3: Find a
a = 4
Step 4: Substitute into the formula
∫ 1 x² + 16 dx = 1 4 tan⁻¹ ( x 4 ) + C
∫ 1 x² + 16 dx = 1 4 tan⁻¹ ( x 4 ) + C
Question 02 • Direct

Evaluate the following integral.

∫ 1 x² + 121 dx
Complete Solution

a² = 121
Step 2: Find a
a = 11
Step 3: Apply the standard result
∫ 1 x² + 121 dx = 1 11 tan⁻¹ ( x 11 ) + C
∫ 1 x² + 121 dx = 1 11 tan⁻¹ ( x 11 ) + C
Question 03 • Factor First

Evaluate the following integral.

∫ 1 4x² + 100 dx
Complete Solution
Step 1: Factor the denominator
4x² + 100 = 4(x² + 25)
Step 2: Rewrite the integral
∫ 1 4(x² + 25) dx = 1 4 ∫ 1 x² + 25 dx
Step 3: Identify a
a² = 25
a = 5
Step 4: Apply the formula
1 4 × 1 5 tan⁻¹ ( x 5 ) + C
∫ 1 4x² + 100 dx = 1 20 tan⁻¹ ( x 5 ) + C
Question 04 • The a² Trap

Evaluate the following integral.

∫ 1 x² + 36 dx
Complete Solution
Step 1: Identify a² carefully

The denominator is x² + 36, so the number 36 represents a², not a.

a² = 36
Step 2: Find a
a = √36 = 6
Step 3: Apply the formula
∫ 1 x² + 36 dx = 1 6 tan⁻¹ ( x 6 ) + C
∫ 1 x² + 36 dx = 1 6 tan⁻¹ ( x 6 ) + C
Question 05 • Numerator Trap

Evaluate the following integral.

∫ 3 x² + 9 dx
Complete Solution
Step 1: Take the constant outside
∫ 3 x² + 9 dx = 3 ∫ 1 x² + 9 dx
Step 2: Identify a
a² = 9
a = 3
Step 3: Apply the standard result
3 × 1 3 tan⁻¹ ( x 3 ) + C
Step 4: Simplify
3 × 1 3 = 1
∫ 3 x² + 9 dx = tan⁻¹ ( x 3 ) + C
Question 06 • Hidden Form

Evaluate the following integral.

∫ 1 9x² + 16 dx
Complete Solution
Step 1: Factor the denominator
9x² + 16 = 9 ( x² + 16 9 )
Step 2: Rewrite the integral
∫ 1 9x² + 16 dx = 1 9 ∫ 1 x² + 16 9 dx
Step 3: Identify a
a² = 16 9
a = 4 3
Step 4: Apply the formula
1 9 × 3 4 tan⁻¹ ( x 4 3 ) + C
Step 5: Simplify
1 9 × 3 4 = 1 12
∫ 1 9x² + 16 dx = 1 12 tan⁻¹ ( 3x 4 ) + C
Question 07 • Challenge

Evaluate the following integral.

∫ 1 25x² + 49 dx
Complete Solution
Step 1: Factor the denominator
25x² + 49 = 25 ( x² + 49 25 )
Step 2: Rewrite the integral
∫ 1 25x² + 49 dx = 1 25 ∫ 1 x² + 49 25 dx
Step 3: Identify a
a² = 49 25
a = 7 5
Step 4: Apply the standard result
1 25 × 5 7 tan⁻¹ ( x 7 5 ) + C
Step 5: Simplify
1 25 × 5 7 = 1 35
∫ 1 25x² + 49 dx = 1 35 tan⁻¹ ( 5x 7 ) + C
