Integration is more than finding an antiderivative. It connects area, accumulation, substitution, algebra, trigonometry and differentiation into one powerful idea.

In this chapter, you will develop a collection of techniques for evaluating integrals. Start with numerical integration, learn to recognize standard forms, and then progress through trigonometric relationships, partial fractions, substitution and integration by parts.

TOPIC 01

Trapezium Rule

The Trapezium Rule is a numerical method used to estimate the value of a definite integral when an exact integration may be difficult or when a numerical approximation is required.

The idea

Instead of finding the exact area under a curve, we divide the interval into strips and approximate each strip using a trapezium.

∫ₐᵇ f(x) dx ≈ h/2 [f(a) + f(b) + 2(f(a+h) + f(a+2h) + ... + f(b-h))]
where h = (b − a) / n

Worked Example

EXAMPLE

Use the Trapezium Rule with 4 strips to estimate ∫₀⁴ x² dx.

Step 1: Find the width of each strip.
h = (4 − 0)/4 = 1
Step 2: Calculate the function values.
f(0)=0,   f(1)=1,   f(2)=4,   f(3)=9,   f(4)=16
Step 3: Substitute into the Trapezium Rule.
A ≈ 1/2 [0 + 16 + 2(1 + 4 + 9)]
A ≈ 17
EDUNOVA TIP

Always calculate h first. A common mistake is using the number of strips as the strip width.

Practice

  1. Use 4 strips to estimate ∫₀⁴ x³ dx.
  2. Use 5 strips to estimate ∫₀⁵ (x² + 1) dx.
  3. Explain why the Trapezium Rule gives an approximation.
TOPIC 02

Recognize Integrals

Some integrals can be evaluated immediately if you recognize them as standard forms. The key is to identify the function before applying a technique.

Basic Power Rule

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C

This rule applies when n ≠ −1.

Important Standard Integrals

∫ 1/x dx = ln|x| + C
∫ eˣ dx = eˣ + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C

Worked Example

EXAMPLE

Evaluate:

∫ (3x² + 4x − 5) dx
Integrate each term separately.
3(x³/3) + 4(x²/2) − 5x + C
x³ + 2x² − 5x + C
RECOGNITION CHECK

Before using a complicated method, ask yourself: "Does this integral already match a standard form?"

Practice

  1. Evaluate ∫(5x⁴ − 2x² + 7)dx.
  2. Evaluate ∫cos x dx.
  3. Evaluate ∫(1/x)dx.
TOPIC 03

Integration Using Trigonometrical Relationships

Trigonometric identities allow complicated-looking integrals to be rewritten into forms that are easier to integrate.

Useful Relationships

sin²x + cos²x = 1
1 + tan²x = sec²x
1 + cot²x = cosec²x

Double-Angle Relationships

cos 2x = 1 − 2sin²x
cos 2x = 2cos²x − 1

Worked Example

EXAMPLE

Evaluate:

∫ sin²x dx
Use:
sin²x = (1 − cos 2x)/2
Therefore:
∫sin²x dx = ∫(1 − cos 2x)/2 dx
Integrate:
x/2 − sin 2x/4 + C
EDUNOVA TIP

Don't integrate a complicated trigonometric expression immediately. First look for an identity that simplifies it.

Practice

  1. Evaluate ∫cos²x dx.
  2. Evaluate ∫tan²x dx.
  3. Rewrite sin²x using a double-angle identity.
TOPIC 04

Integration of 1/(x² + a²)

One particularly important standard integral is the form involving x² + a².

∫ dx/(x² + a²) = (1/a) tan⁻¹(x/a) + C

The constant a must be positive in this standard form.

Worked Example

EXAMPLE

Evaluate:

∫ dx/(x² + 9)
Compare the denominator with x² + a².
a² = 9
a = 3
Apply the standard result.
(1/3)tan⁻¹(x/3) + C
RECOGNITION CHECK

Look specifically for x² + a². This form leads directly to an inverse tangent result.

Practice

  1. Evaluate ∫dx/(x² + 4).
  2. Evaluate ∫dx/(x² + 25).
  3. Evaluate ∫dx/(x² + 16).
TOPIC 05

Integrating Functions in the Form f'(x)/f(x)

When the numerator is the derivative of the denominator, the integral has a particularly simple form.

∫ f'(x)/f(x) dx = ln|f(x)| + C

Why?

The derivative of ln|f(x)| is f'(x)/f(x), by the chain rule.

Worked Example

EXAMPLE

Evaluate:

∫ (2x)/(x² + 5) dx
The denominator is x² + 5. Its derivative is 2x.
Therefore the integral matches the standard form.
ln(x² + 5) + C

Another Example

∫ (3x²)/(x³ + 7) dx
ln|x³ + 7| + C
FAST CHECK

Differentiate the denominator mentally. If you get the numerator, think "ln".

Practice

  1. Evaluate ∫(2x)/(x²+1) dx.
  2. Evaluate ∫(6x²)/(2x³+4) dx.
  3. Evaluate ∫(1)/(x+3) dx.
TOPIC 06

Integration Using Partial Fractions

Partial fractions allow a rational expression to be separated into simpler fractions that can be integrated individually.

Basic Idea

Suppose we have:

1/[(x+a)(x+b)]

We can rewrite it as:

A/(x+a) + B/(x+b)

Worked Example

EXAMPLE

Evaluate:

∫ dx/[(x+1)(x+2)]
Write:
1/[(x+1)(x+2)] = A/(x+1) + B/(x+2)
Multiply through by (x+1)(x+2):
1 = A(x+2) + B(x+1)
Comparing coefficients gives:
A = 1,   B = −1
Therefore:
∫[1/(x+1) − 1/(x+2)]dx
ln|x+1| − ln|x+2| + C
EDUNOVA TIP

Factor the denominator completely before setting up your partial fractions.

Practice

  1. Decompose 1/[(x+2)(x+3)] into partial fractions.
  2. Evaluate ∫dx/[(x+2)(x+5)].
  3. Decompose (3x+1)/[(x+1)(x+2)].
TOPIC 07

Integration Using Substitution

Integration by substitution is based on reversing the chain rule. We replace a complicated expression with a new variable.

The Method

Let u = g(x)

du = g'(x) dx

The integral can then be rewritten entirely in terms of u.

Worked Example

EXAMPLE

Evaluate:

∫ 2x(x²+1)³ dx
Let:
u = x² + 1
Differentiate:
du = 2x dx
Substitute:
∫u³ du
Integrate:
u⁴/4 + C
Replace u:
(x² + 1)⁴/4 + C
SUBSTITUTION CHECK

Choose a substitution that makes the integral simpler, not more complicated. Look for an expression and its derivative appearing together.

Practice

  1. Evaluate ∫2x(x²+4)⁵ dx.
  2. Evaluate ∫cos x(sin x)⁴ dx.
  3. Evaluate ∫3x²(x³+1)⁶ dx.
TOPIC 08

Integration by Parts

Integration by parts is useful when the integrand is a product of two functions. It comes from reversing the product rule for differentiation.

∫u dv = uv − ∫v du

Choosing u

A useful strategy is to choose u as the function that becomes simpler when differentiated. The remaining part becomes dv.

Worked Example

EXAMPLE

Evaluate:

∫x eˣ dx
Choose:
u = x
dv = eˣ dx
Therefore:
du = dx
v = eˣ
Apply the formula:
∫u dv = uv − ∫v du
= xeˣ − ∫eˣ dx
xeˣ − eˣ + C

Another Important Example

∫x sin x dx

Choose u = x and dv = sin x dx. Then du = dx and v = −cos x.

∫x sin x dx = −x cos x + ∫cos x dx
−x cos x + sin x + C
EDUNOVA TIP

If you're unsure what to choose for u, select the function that becomes simpler after differentiation.

Practice

  1. Evaluate ∫x cos x dx.
  2. Evaluate ∫x eˣ dx.
  3. Evaluate ∫x ln x dx.
